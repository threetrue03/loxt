# LOXT v1.11.0

이번 버전은 보관함 안정성과 Work·Live 사용 흐름, 많은 기록과 긴 음성의 처리 부담을 개선했습니다.

### 안정성
- Live 폴더 삭제 후 화면이 사라지는 문제 수정.
- 화자 분석이 실패하거나 중단돼도 기본 스크립트와 원본 보존. 화자 분석만 다시 시도 가능.
- 손상된 보관함 목록을 백업과 녹음별 정보로 복구하고 복구 한계 안내.
- 제목 저장 실패 안내, 빠른 연속 편집 보호, Live 파일별 가져오기 결과와 실패 파일 재시도.

### 사용성
- Live 준비 취소와 Work 작업 대기 이유 표시.
- Work·Live 재변환 시 기존 하위 폴더 유지.
- 복사·내보내기에 화자 표시 포함.
- 모달·드롭다운·폴더 이동 메뉴의 키보드 포커스 개선.
- 작은 창과 확대 상태의 재생·녹음 패널, 사이드바 접근성 개선.
- 카드 날짜·시간·상태·미리보기 가독성 개선. 기존 SUIT와 다크·라이트 디자인 유지.
- 설치 프로그램의 브랜드·모델 이름과 준비 실패 안내 통일.

### 성능
- 목록의 숨겨진 스크립트와 화면 밖 카드 렌더링 부담 축소.
- 진행률 변화와 보관함 변경을 분리해 불필요한 전체 목록 조회 제거.
- Live 시간·입력 레벨과 스크립트 전달 분리, 체크포인트 저장 비용 축소.
- 긴 음성의 배열 복사를 줄이고 디스크 매핑으로 RAM 사용 개선.
- 연속 Work 변환에서 같은 모델 재사용. 30초 유휴 또는 Live 전환·모델 변경·취소·오류·앱 종료 시 해제.

### 업데이트
Windows 설치 파일 `LOXT-Setup-1.11.0-x64.exe`를 실행하세요. 기존 녹음·스크립트·폴더·모델·설정과 저장 경로를 유지합니다.

실행 환경과 음성 길이에 따라 속도·메모리 사용·화자 구분 결과는 달라집니다. 디스크 매핑은 긴 음성 처리 시 추가 임시 저장 공간을 사용합니다.
