# LOXT v2.6.0

내 PC에서 사용할 음성 인식 모델을 검색하고 설치하는 **모델 스토어**를 추가했습니다.

- **모델 검색·설치**: Hugging Face의 공개 음성 인식 모델을 검색하고 제공자·언어·용량·라이선스·지원 상태를 확인할 수 있습니다. 현재 설치 대상은 호환되는 CTranslate2 Whisper 모델입니다. 다른 엔진의 모델은 지원 예정으로 구분합니다.
- **홈에서 모델 선택**: 현재 모드의 저성능·표준·고성능 모델을 홈에서 선택하고 스토어로 이동할 수 있습니다.
- **Work·Live별 모델 관리**: 세 역할을 각 모드에서 따로 지정하고 별명·태그와 기본 모델을 관리합니다. 설치 파일은 공유하며 지정하지 않은 모델은 기타 모델, 직접 가져온 모델은 외부 모델로 표시합니다.
- **내 PC 성능 확인**: 예시 음성으로 모델 로딩·파일 변환·Live 청크 처리 시간을 측정합니다. 예상 추천과 실측 결과를 구분하며, 정확도나 전체 Live 지연을 측정한 것으로 표시하지 않습니다.
- **검증된 다운로드**: 특정 버전의 파일을 다운로드하고 해시와 실제 모델 로딩을 검사한 뒤 등록합니다. 취소 후 이어받기, 실패한 업데이트의 기존 모델 보존과 중단된 설치 복구를 지원합니다.
- **업데이트 직접 선택**: 설치 모델의 새 버전은 상세에서 확인하고 사용자가 설치합니다. 목록은 24시간, 검색 결과는 15분 캐시하며 새로고침으로 갱신할 수 있습니다.

기존 녹음·스크립트·메모·PDF·폴더·모델·설정은 유지됩니다. 신규 Live 녹음은 PC 전용이며 Whisper 청크 변환 방식을 유지합니다. 한국어 특화 모델·별도 스트리밍 엔진을 모두 지원한다는 의미는 아닙니다.

설치 파일: **LOXT-Setup-2.6.0-x64.exe** · Windows x64

소개 사이트와 README의 설명·예시 화면·다운로드 링크를 v2.6.0에 맞췄습니다. 공개 다운로드는 GitHub에 설치 파일을 업로드한 뒤 제공됩니다.
