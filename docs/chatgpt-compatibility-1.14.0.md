# ChatGPT 호환성 검증 — LOXT 1.14.0

## 검사 대상

- 실제 배포용 `release/stage5/win-unpacked/LOXT.exe`.
- 기존 테스트 전용 브라우저가 아니라 앱의 오른쪽 브라우저 탭.
- 사용자 데이터와 분리된 `test-results/chatgpt-1.14.0/profile`.
- 기존과 동일한 `persist:loxt-browser` 저장 공간과 보안 설정.
- 버전은 1.14.0을 유지한다. 일반 실행 상태와 자동화 도구가 연결된 상태를 구분한다.

## 현재 확인한 결과

| 항목 | 상태 |
| --- | --- |
| 패키징 앱 실행·브라우저 탭 열기 | 확인 |
| ChatGPT 탐색 | 일반 실행 앱에서 성공 |
| 직접 로그인 | 일반 실행 앱에서 성공. 사용자가 “Google 이메일 계정”으로 완전히 로그인했다고 확인 |
| 메시지 전송·응답 | 성공. 사용자가 테스트 질문의 실제 답변 수신 확인 |
| 앱 정상 종료·재실행 후 로그인 유지 | 성공. 사용자가 재로그인 없이 메시지 응답까지 정상이라고 확인 |

처음 Playwright로 시작한 앱에서는 사용자가 Cloudflare 확인 반복을 재현했다. 자동화 연결 없이 동일한 패키지·동일한 분리 프로필을 일반 실행하고, 기존 두 번째 실행 기능으로 창을 표시한 뒤 직접 로그인에 성공했다. 로그인 성공에 맞추기 위한 앱 코드·브라우저 식별 정보·권한 변경은 하지 않았다.

Cloudflare는 자동화 브라우저가 실제 서비스 보안 확인을 해결하는 환경을 지원하지 않는다고 명시한다. 따라서 최초 자동화 실행 실패를 일반 사용자 환경 전체의 실패로 판단하지 않는다. 다만 확인 반복의 정확한 원인을 자동화 연결 하나로 단정하지도 않는다. 사용자 확인은 Google 이메일 계정이라는 표현이며, Google OAuth와 Gmail 주소·비밀번호 로그인 중 어느 방식인지 아직 별도로 구분하지 않았다.

## 검증 절차

1. 자동화 연결 없이 패키징된 앱을 별도 프로필로 연다. `scripts/chatgpt-app-check.mjs`는 최초 자동화 실행과 비교 조건을 재현하는 도구이며, 실제 서비스 로그인 성공 여부의 최종 검증 수단으로 사용하지 않는다.
2. 사용자가 보안 확인과 로그인을 직접 수행한다. 비밀번호·인증 코드·세션 쿠키는 수집하지 않는다.
3. 사용자가 “LOXT 연결 확인이라고 답해줘”를 보내 응답을 확인한다. 로그인 방식과 성공 여부만 기록한다.
4. 첫 검증 완료 후 앱을 정상 종료하고 동일한 프로필로 재실행한다. 복원된 ChatGPT 탭에서 재로그인 필요 여부와 다시 메시지를 보낼 수 있는지 확인한다.
5. 성공한 조건과 실패한 조건을 README·릴리스·검증 문서에 반영한다. 실패한 경우 먼저 원인을 확인하고 필요한 앱 변경을 제안한다.

검증 실행 도구는 `test-results/chatgpt-1.14.0/command.json`의 `restart`, `record`, `stop` 명령을 받는다. 명령마다 고유 `id`를 사용한다. 결과 파일에는 성공 여부만 기록하며 실제 계정의 인증 자료나 대화 내용을 기록하지 않는다. 브라우저의 로그인 저장 자료 자체는 분리된 로컬 테스트 프로필 안에만 남는다.

## 최종 검증 결과 — 2026-10-06

사용자가 직접 로그인과 메시지 응답을 확인했다. 메인 프로세스 10928을 정상 종료한 뒤 동일한 프로필의 새 프로세스 24032로 재실행했고, 저장된 ChatGPT 탭을 열었다. 사용자는 “재로그인 없이 메시지 응답도 정상”이라고 확인했다. 기존 프로세스를 띄워 두고 새 창만 만든 검사는 아니다.

앱 브라우저 코드·보안 설정·브라우저 식별 정보를 변경하지 않고, 이미 생성한 1.14.0 패키지에서 세 단계를 확인했다. 따라서 기존 1.14.0 설치 파일을 그대로 사용할 수 있다. 계정별 로그인 방식·기기·네트워크·장기간 세션 만료 조건을 모두 검증했다는 의미는 아니다.

최초 자동화 실행 조건의 Cloudflare 확인 반복과 일반 실행 성공을 모두 기록한다. 검증의 성공 판정은 일반 실행 상태의 직접 확인을 기준으로 한다. 인증 페이지는 자동화하지 않았고 실제 계정 대화를 캡처·릴리스 이미지로 사용하지 않았다.

## 공식 안내와 한계

OpenAI는 Cloudflare 확인 반복에 대한 안내를 제공한다. 쿠키·JavaScript, 브라우저 프로필과 네트워크 환경 등을 점검하도록 안내하지만 이 문서만으로 Electron 내장 브라우저의 로그인이 보장되지는 않는다.

[OpenAI 로그인 문제 안내](https://help.openai.com/en/articles/7426629-why-cant-i-log-in-to-chatgpt)

[Cloudflare 지원 브라우저와 자동화 환경 제한](https://developers.cloudflare.com/cloudflare-challenges/reference/supported-browsers/)

보안 확인을 우회하거나 브라우저 식별 정보를 속이는 변경은 하지 않는다. 인증은 직접 수행하고 테스트 결과를 기준으로 지원 범위를 판단한다.
