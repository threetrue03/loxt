# LOXT 2.0.0 — 내 기기 연결

각 사용자의 PC가 자신의 보관함과 변환을 담당합니다. 개발자의 공용 서버나 클라우드 보관함에 저장하는 구조가 아닙니다. 모바일 연결은 기본적으로 꺼져 있으며 기존 PC 사용에는 필요하지 않습니다.

## 처음 연결

1. PC와 iPhone/iPad를 같은 Wi-Fi에 연결하고 PC의 **설정 → 내 기기 연결**을 켭니다.
2. PC 화면에 표시된 주소와 인증서 안내를 사용합니다. 여러 네트워크 어댑터가 있으면 Wi-Fi 주소를 확인하세요.
3. iPhone/iPad에서 안내된 인증서를 내려받습니다. **설정 → 일반 → VPN 및 기기 관리**에서 프로파일을 설치합니다. 이어서 **일반 → 정보 → 인증서 신뢰 설정**에서 해당 LOXT 인증서를 신뢰합니다. OS별 메뉴 명칭은 다를 수 있습니다.
4. PC에 표시된 인증서 지문과 설치한 인증서의 지문을 비교합니다. 초기 인증서 안내용 HTTP 주소에서는 보관함 데이터를 제공하지 않습니다.
5. PC의 QR 또는 HTTPS 주소로 접속하고 **PC에서 연결 요청을 승인**합니다. QR은 제한 시간 뒤 만료되며 재사용하지 않습니다.
6. 승인 후 같은 Work·Live 보관함이 열립니다. 다음 접속에서 유효한 승인 세션을 재사용합니다. 서버를 끄거나 PC를 종료하면 접속할 수 없습니다.

Windows 방화벽이 묻는 경우 신뢰하는 **개인 네트워크**에서 LOXT 연결을 허용하세요. 같은 Wi-Fi에서도 게스트 네트워크나 공유기의 기기 간 통신 차단이 켜져 있으면 접속할 수 없습니다. 공유기의 포트 전달이나 인터넷 공개를 요구하지 않습니다.

## 사용할 수 있는 기능

| 기능 | 모바일 |
| --- | --- |
| 폴더·검색·휴지통·기록 확인 | 연결한 PC의 같은 보관함 |
| 메모·PDF 편집 | 자동 저장, 충돌 알림, 임시 입력 복구 |
| 스크립트·원본 재생·내보내기 | PC의 저장된 기록 |
| Work 마이크 녹음·음성/PDF 업로드 | 전경 사용, 업로드 진행 상태 |
| Work 변환 | PC의 설치 모델·GPU 또는 CPU |
| 저장된 Live 기록·메모·PDF | 확인·편집 가능 |
| 신규 Live 녹음·컴퓨터 소리·모델 설치/삭제·PC 파일 경로 탐색 | 제공하지 않음 |

모델 목록은 PC에 설치된 기본·외부 모델을 반영합니다. 모델 파일 다운로드와 실행 환경 준비는 다른 작업입니다. 파일이 이미 있어도 PC에서 처음 사용하는 GPU 환경에는 추가 구성요소 다운로드가 필요할 수 있습니다. 변환을 수락한 뒤 모바일 연결이 끊겨도 PC의 작업은 계속됩니다.

## 저장과 복구

- PC가 기준 데이터를 관리하며 모바일마다 별도 공식 보관함을 만들지 않습니다.
- 같은 메모·PDF를 동시에 수정하면 revision 충돌을 안내합니다. 최신 내용을 확인하거나 자신의 편집을 사본으로 저장하세요.
- 미완료 모바일 녹음은 해당 호스트의 IndexedDB에 임시 원본 조각을 보존합니다. 새로고침 뒤 **원본 받기 / PC에 복구 사본 저장**을 사용하세요. PC에 이미 저장한 원본도 유지합니다.
- 임시 녹음에는 128 MB 한도와 브라우저 저장 공간 제한이 있습니다. 브라우저 데이터를 삭제하면 임시 내용과 로그인 상태가 사라질 수 있습니다. 잠금·다른 앱 전환·강제 종료에서 녹음 지속이나 모든 미저장 입력 보존을 보장하지 않습니다.
- 모바일 Markdown·HTML 내보내기는 첨부파일을 함께 포함한 ZIP을 사용합니다.

## 연결 해제와 문제 해결

- PC 설정에서 승인 기기를 해제하면 해당 기기의 연결 권한이 즉시 취소됩니다. 연결을 끄면 서버·연결이 종료됩니다.
- PC IP가 달라지면 현재 설정에 표시된 주소로 다시 접속하세요. 인증서가 갱신된 경우 안내에 따라 새 인증서를 설치·신뢰해야 합니다.
- 홈이 열리지 않으면 PC 켜짐, 연결 설정, 같은 네트워크, Wi-Fi 기기 격리와 방화벽을 확인하세요.
- 마이크 권한 오류는 Safari 사이트 마이크 허용과 HTTPS 인증서 신뢰 상태를 확인하세요.
- 변환이 오래 준비 중이면 PC의 변환 작업 상태에서 실행 환경 다운로드인지 실제 추론인지 확인하세요.
- PDF 오류는 **PDF 오류 상세**를 함께 기록하세요. 최대 파일 크기, 손상·암호화 여부도 확인합니다.

실제 iPhone Safari에서 홈·메모 수정·PDF 필기/재열기·마이크 녹음·PC CUDA 변환·모델 네 개 표시·스크립트와 원본 재생을 사용자가 확인했습니다. iPad Pencil, 외장 키보드와 모든 기기 조합을 검증한 것은 아닙니다.
