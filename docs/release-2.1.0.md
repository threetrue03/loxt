# LOXT v2.1.0

모바일 탐색과 내 PC 웹 화면으로 연결하는 흐름을 개선했습니다.

## 추가

- 좁은 모바일 웹 화면에 **홈·보관함·최근·설정 하단 탐색**을 추가했습니다. Work·Live에 함께 적용됩니다.
- 메모·PDF·녹음·스크립트 상세에서는 탐색 바를 숨겨 편집 공간을 확보하고, 보관함에서 휴지통을 열 수 있습니다. 넓은 웹 화면과 PC 앱은 기존 사이드바를 사용합니다.
- 소개 사이트 상단의 **LOXT로 가기**와 다운로드 아래 **이미 설치하셨다면 LOXT로 이동해보세요**에서 개인 PC의 웹 연결 주소를 등록하고 이동할 수 있습니다.
- 사이트는 재접속 주소만 해당 브라우저에 저장하며, 연결 주소 변경·삭제를 제공합니다. QR의 승인 토큰은 저장하지 않습니다.

## 수정

- PC 설정 → 내 기기 연결의 주소 복사를 Windows 클립보드로 처리하고, 복사 성공·실패를 표시합니다.
- 처음 연결할 **5분 유효 주소**와 승인한 브라우저의 **재접속 주소**, 인증서 설치용 **초기 설정 주소**를 구분했습니다.
- 만료되거나 사용한 연결 주소는 복사 시 새로 발급하며, 서버가 꺼지면 이전 주소를 표시하지 않습니다.
- 기존 녹음·메모·PDF·스크립트·폴더·모델·설정과 Work·Live 분리를 유지합니다.

## 연결 안내

PC에서 LOXT를 실행하고 설정 → 내 기기 연결을 켜세요. 처음 연결하는 모바일은 같은 Wi-Fi에서 인증서를 설치·신뢰한 뒤 QR 또는 연결 주소를 열고 **PC에서 승인**합니다. 소개 사이트가 개인 PC를 자동 검색하거나 PC 앱을 대신 실행하지는 않습니다.

모바일 신규 Live 녹음은 PC 전용이며, 모바일 Work 녹음은 브라우저를 연 전경 사용 기준입니다. PC 앱이 종료되거나 다른 네트워크로 이동하면 연결할 수 없습니다.
