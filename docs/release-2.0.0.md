# LOXT v2.0.0

PDF를 읽고 필기하며, 같은 Wi-Fi의 모바일에서도 내 PC 보관함을 이어서 사용하세요.

## 추가

- **PDF 읽기·필기**: Work·Live의 PDF 불러오기, 페이지 미리보기 열기/닫기, 확대·맞춤 보기, 텍스트 검색·선택·복사.
- 펜·형광펜·지우개·텍스트·도형, 실행 취소와 자동 저장. 원본은 유지하고 원본 PDF 또는 필기 포함 PDF로 내보냅니다.
- **내 기기 연결**: PC에서 켜는 개인 HTTPS 연결, 인증서 안내, QR 연결과 PC 승인, 승인 기기 해제.
- 승인한 모바일에서 같은 폴더·메모·PDF·스크립트·원본을 확인하고 수정합니다. 동시 편집 충돌과 저장 실패를 안내하고 임시 내용·복구 사본을 보존합니다.
- 모바일 Work 마이크 녹음·음성 파일 업로드와 **PC에 설치한 모델을 사용하는 변환 요청**. 변환은 PC의 GPU 또는 CPU에서 진행됩니다.
- 폴더 ZIP 내보내기에 PDF 원본과 필기 JSON을 포함합니다.

## 수정

- Work의 일시정지와 최종 중단을 구분했습니다. 최종 중단은 원본을 저장하고 왼쪽 **버리기**, 오른쪽 단독 **변환하기**를 표시합니다. 선택 창 안의 버리기와 중단 후 장치 드롭다운을 제거했습니다.
- 다크·라이트 테마에서 녹음 버튼의 호버·포커스 대비를 정리했습니다.
- 좁은 창과 패널 분할에서 제목·보관함 도구 모음·설정·메모 버튼 잘림을 개선하고 스크립트 내보내기를 주변 버튼 크기에 맞췄습니다.
- 모달의 배경 흐림과 조작 차단이 로고·상단 바까지 적용됩니다.
- Safari PDF 텍스트 읽기 호환성과 터치 필기 시 페이지가 움직이는 문제를 수정했습니다.
- 기존 Work·Live 기록·메모·폴더·모델·설정과 저장 위치를 유지합니다.

## 사용 조건

- Windows x64 설치본입니다. 모바일은 별도 네이티브 앱이 아닌 승인된 웹 접속입니다.
- 같은 Wi-Fi, 켜져 있는 PC, 인증서 설치·신뢰와 PC 승인이 필요합니다. 개인 네트워크 방화벽 허용이 필요할 수 있습니다.
- 모바일 Work 녹음은 Safari 화면을 연 전경 사용 기준입니다. 잠금·다른 앱 전환 중 녹음 지속을 보장하지 않습니다. 신규 Live 녹음과 컴퓨터 소리 녹음은 PC 전용입니다.
- 최초 모델 실행 환경 준비에는 인터넷과 추가 공간·시간이 필요할 수 있습니다.
- PDF는 최대 128 MB이며 암호화 문서는 해제 사본을 사용하세요. 스캔 문서 OCR은 포함하지 않습니다.
