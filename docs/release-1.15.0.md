# LOXT v1.15.0

녹음 중 메모와 내보내기를 개선하고 탭·폴더 조작을 정리했습니다.

## 추가 및 개선

- 녹음 중단 시 바로 창을 열지 않고 일시정지하며 버튼을 변환하기로 변경합니다. 변환하기를 눌러 폴더·모델 선택 창을 열고, 창을 닫거나 녹음 계속으로 재개할 수 있습니다.

- Work에서도 녹음 중 메모를 작성할 수 있습니다. 페이지를 이동하거나 녹음을 저장해도 메모를 보존합니다.
- 폴더 내보내기를 추가했습니다. ZIP에 하위 폴더·빈 폴더·원본 음성·스크립트 TXT·메모 Markdown·참조된 첨부파일을 담습니다. 휴지통 기록은 제외합니다.
- 스크립트 내보내기에 PDF를 추가했습니다. 메모 PDF 저장 오류를 수정하고 글꼴·이미지 로딩 후 출력하도록 개선했습니다.
- 상단 패널 아이콘은 기존 탭을 다시 엽니다. Ctrl+T로 탭을 추가하고 Ctrl+W로 선택한 오른쪽 탭을 닫습니다.
- 사이드바의 폴더 +는 현재 경로 아래에서 이름을 입력하도록 개선했습니다. 빈 이름은 생성하지 않습니다.
- 메모의 블록 추가 버튼과 하단 안내를 제거했습니다. / 메뉴·블록 이동·서식은 유지합니다.
- Markdown 자동 변환 직후 Escape를 누르면 원래 입력 기호로 돌아갑니다.
- 새 Work 변환에서는 화자 분석을 실행하지 않습니다. Live 화자 분석과 기존 기록의 화자 표시는 유지합니다.
- 홈·폴더에서 불필요한 텍스트 드래그를 막고 스크립트·메모·입력칸의 선택은 유지했습니다.
- Live 듣기 상태의 불필요한 안내 문구를 제거했습니다.

## 사용 안내

- 폴더 내보내기는 해당 폴더의 녹음을 종료한 뒤 사용할 수 있습니다. Markdown은 색상 등 일부 서식을 단순화합니다.
- 기존 녹음·스크립트·메모·폴더·모델·설정은 유지됩니다.
- 이번 업데이트에는 Live 음성 인식 성능 변경이나 Windows 음소거 상태의 시스템 오디오 캡처 변경이 포함되지 않습니다.

[Windows 64비트 설치 파일](https://github.com/threetrue03/loxt/releases/download/v1.15.0/LOXT-Setup-1.15.0-x64.exe)

소개 화면은 비공개 예시 프로필과 가상 음성 입력으로 촬영했습니다. 실제 음성 인식 속도·정확도의 검증 자료가 아닙니다.
