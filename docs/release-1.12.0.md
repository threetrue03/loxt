# LOXT v1.12.0

Work·Live 설정을 통일하고, 기본 모델과 개별 변환 모델을 분리했습니다. 기존 SUIT 글꼴과 차콜 색상, 다크·라이트 테마를 유지합니다.

## 설정과 기본값

- Work·Live에 일반, 녹음, 모델 보관함, 저장 공간, 앱 정보를 동일하게 제공합니다.
- 기본 모델·녹음 장치·보관함 보기를 모드별로 저장하고 재실행 시 복원합니다.
- 기존 Work 모델과 화면 설정을 보존해 이전합니다. Live의 기존 표준 모델 초기값을 유지합니다.
- 파일 변환·재변환에서 고른 모델은 해당 작업에만 적용하며 기본값을 변경하지 않습니다.
- 설정에서 모드를 전환해도 현재 탭을 유지하고, 돌아가기를 누르면 기존 녹음·스크립트 화면으로 복귀합니다.

## 모델 관리

- 설치 상태, PC 추천, Work·Live 기본 모델을 각각 표시합니다.
- 설치된 파일과 실행 확인을 구분하고, 확인이 필요한 모델은 자동 검사 또는 사용 확인으로 해결할 수 있습니다.
- 다운로드 %와 실제 준비·검사 단계를 구분합니다. 설치 취소와 오류·재시도를 모델 행에서 안내합니다.
- Live·Work 작업 중에는 모델 변경 제한의 이유를 안내하며, UI와 백엔드가 같은 조건을 적용합니다.
- 모델 삭제 확인에 원본 녹음·스크립트 보존과 기본 모델 재설치 영향을 표시합니다.
- 기본 제공 모델과 외부 모델의 분류를 모델 속성에 맞게 통일합니다.

## 장치·저장·앱 정보

- 연결 해제된 기본 마이크, 장치 정보 조회 실패, 권한 제한을 구분하고 해결 행동을 제공합니다.
- 저장 실패를 안내하고, 저장되지 않은 값을 적용 완료로 표시하지 않습니다.
- Work·Live 보관함과 모델의 실제 사용량·저장 위치·드라이브 여유 공간을 확인할 수 있습니다. 연결 폴더와 중복 파일은 중복 집계하지 않습니다.
- 감지된 GPU, 현재 확인된 실행 장치, 마지막 작업의 실제 실행 장치를 구분합니다.
- 공식 릴리스·라이선스 링크, 설치 로그 열기와 개인 경로·녹음 내용이 제외된 진단 정보 복사를 제공합니다.
- 설정의 글꼴·간격·행 배치를 통일하고 작은 창·확대 화면과 키보드 접근성을 개선합니다.

## 업데이트

Windows 설치 파일 `LOXT-Setup-1.12.0-x64.exe`를 실행하세요. 기존 녹음·스크립트·폴더·모델·설정과 보관함 위치는 유지합니다. 실행 장치는 자동이며 별도 전사 환경 설정을 요구하지 않습니다.

자동 업데이트, 마이크 테스트 녹음, 보관함 이동·백업·일괄 정리는 이번 버전에 추가하지 않았습니다.
