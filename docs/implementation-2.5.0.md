# LOXT 2.5.0 구현 기록

## 범위

승인된 14개 보관함·문서·그리기 개선 사항을 구현했습니다. SUIT, 다크·라이트 테마와 기존 토큰·아이콘을 사용합니다. 기존 사용자 프로필은 검증에 사용하지 않았습니다.

| 요청 | 구현 |
| --- | --- |
| 1·2·12 사이드바·제목 | 하위 폴더 기본 접기, 상위 직계 폴더 표시, 명시적 펼치기 유지, 제목 아이콘, 펼친 상태의 토글 행 정렬 |
| 3·9 단축키 | 도구 호버 안내, 펜·지우개 전환, 형광펜, 도형 메뉴 숫자 선택, 사이드바 Ctrl+Shift+S |
| 4·6 생성 흐름 | 생성·불러오기 그룹, 정확한 용어, 녹음 활동 상태 공유로 중복 시작 방지 |
| 5·10·11 문서 UI | 불필요한 ‘문서’ 제거, 공유 헤더, 녹음·스크립트 전체화면, 연결 메모와 전체 부모 문서 함께 표시 |
| 7·8 선택 메뉴 | 우클릭 대상이 선택돼 있으면 전체 선택 집합의 이동·삭제, 개수 표시, 미선택 대상은 단일 처리 |
| 13 그리기 | 페이지 추가·복제·삭제·실행 취소, 터치 길게 누르기, 필기 미리보기, 안정된 pageId, 변경분 동기화·PDF/ZIP 내보내기 |
| 14 원본 분리 | 별도 음성 휴지통 항목, 스크립트·메모 보존, 원래 기록에 복원, 원래 기록 삭제 후 독립 복원, 중단 복구 저널 |

## 데이터 보존과 동시 편집

그리기의 annotations.json에 pageIds를 저장합니다. 기존 한 페이지 문서는 기록 ID를 첫 페이지 ID로 읽습니다. 페이지 복제 시 페이지와 객체 ID를 새로 만들고 삭제 후 페이지 번호를 다시 배치합니다. 객체 저장·실행 취소·원격 변경에 pageIds를 포함하며 오래된 문서 버전 저장은 기존 충돌 처리로 거부합니다. 페이지 변화는 전체 문서 스냅샷을 저장하고 기존 필기 변경은 변경분 저장을 유지합니다. 재실행 시 문서의 페이지 수로 지연된 목록 메타데이터를 복구합니다.

원본 분리·복원은 audio-transfer.json에 검증된 메타데이터와 이동 계획을 먼저 기록합니다. 음성은 별도의 기록 디렉터리로 이동하고 스크립트·메모는 기존 ID에 남습니다. note.json과 목록을 저장한 뒤 저널을 제거합니다. 중단 시 다시 실행하여 남은 이동을 완료합니다. 휴지통 영구 삭제는 기존 경로 검증과 삭제 저널을 사용합니다. 재생·재변환은 audioMissing 상태에서 막습니다.

현재 실행 세션의 UI 편집 실행 취소와 휴지통 복원은 다른 기능입니다. 그리기 페이지 삭제는 문서 실행 취소로 되돌리고, 녹음 원본은 휴지통 복원으로 되돌립니다.
