# 화자 분리 — 후속 작업

상태: LOXT 1.7.0 구현 완료. 아래는 LOXT 1.6.1 당시의 후속 설계 기록이다.

- 같은 녹음의 목소리를 A/B/C로 구분하고 같은 화자가 다시 말하면 기존 식별자를 유지한다.
- 스크립트 시간 옆에 기존 SUIT와 차콜 UI에 맞는 작은 화자 배지를 배치한다.
- Work는 전체 원본 분석, Live는 임시 식별 후 녹음 종료 시 전체 결과 보정을 검토한다.
- 별도의 화자 분석 모델이 필요하다. RTX 2060 6GB에서 Whisper와 함께 사용할 때 메모리, 처리 속도와 GPU 작업 순서를 검증한 뒤 범위를 확정한다.
- 발화 중첩과 짧은 발화, 잡음, 화자 수 변화에 대한 정확도를 검증하고 추가 모델의 배포 조건도 확인한다.

컴퓨터 소리 출력 장치 자동 추적은 기존 `system-audio-device-following.md`를 따른다. 두 기능 모두 이번 변경과 분리해 보관한다.

후속 보류 범위를 구현했습니다. 자세한 구성·검증·제약은 `../verification-1.7.0.md`를 참고합니다. 기존 설계 이력은 보존합니다.
