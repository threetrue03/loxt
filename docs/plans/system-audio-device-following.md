# 컴퓨터 소리 출력 장치 자동 추적

상태: LOXT 1.7.0 구현 완료. 아래는 최초 설계 기록이며, 실제 검증 범위는 마지막 구현 항목을 참고한다.
기록일: 2026-10-04

## 목표

사용자가 스피커, 유선 이어폰, USB 헤드셋, 블루투스 이어폰으로 듣는 컴퓨터 소리를 Work와 Live에서 녹음한다. 녹음 중 장치를 연결하거나 분리해도 같은 녹음과 스크립트 세션을 유지한다.

## 합의한 동작

- 기본은 Windows의 현재 기본 출력 장치를 자동으로 따라간다.
- 헤드셋·이어폰을 연결한 뒤 시작하면 해당 출력의 소리를 녹음한다.
- 진행 중 기본 출력이 변경되면 변경을 감지하고 새 입력 스트림에 연결한다.
- 블루투스 일시 단절에는 녹음 세션을 유지하며 재연결을 시도한다. 실패하면 저장된 내용을 유지하고 안내한다.
- 기존 메뉴의 ‘컴퓨터 소리’를 유지하고 현재 출력 장치 이름을 보조 정보로 표시한다.
- 자동 전환 과정에서 기존 파일, 확정 스크립트, 구간 시간 정렬을 보존한다. 전환 중 실제 수집하지 못한 소리가 있으면 이를 숨기지 않는다.

## 구현 전 검증 순서

1. 기존 Electron `audio: 'loopback'` 방식으로 유선·USB·블루투스 출력에서 녹음을 확인한다.
2. 녹음 중 연결·분리·기본 출력 변경·블루투스 재연결을 시험한다. 마이크 사용에 따른 블루투스 출력 프로필 변경도 확인한다.
3. 기존 방식으로 안정적인 자동 전환과 장치 확인이 가능한 범위를 판단한다.
4. 제어가 부족하면 Windows WASAPI 루프백 모듈로 출력 장치 탐색, 변경 알림, 캡처 재연결을 구현한다. Electron 메뉴 변경만으로 특정 출력 장치 지정이 가능하다고 가정하지 않는다.

## 보류 사항

- 앱별로 서로 다른 출력 장치를 사용하는 경우의 녹음 범위와 수동 장치 선택은 검증 후 결정한다.
- 모든 출력 장치를 동시에 합쳐 녹음하는 기능은 현재 합의 범위에 포함하지 않는다.
- 이 문서는 후속 구현을 위한 기록이며, 녹음 로직은 변경하지 않았다.
