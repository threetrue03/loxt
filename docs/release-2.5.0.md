# LOXT 2.5.0

보관함 정리, 문서 집중 화면과 그리기 페이지 관리를 개선했습니다.

## 변경 사항

- 사이드바는 내 보관함 바로 아래 폴더만 기본으로 보여주고 하위 폴더는 접어 둡니다. 열린 사이드바에 ‘사이드바 닫기’를 표시하고 Ctrl+Shift+S로 열고 닫을 수 있습니다.
- 홈·최근 기록·휴지통 제목에 사이드바와 같은 아이콘을 표시합니다.
- 새로 추가하기를 폴더 / 새 녹음·새 메모·새 그리기 / 녹음·YouTube·PDF 불러오기 세 그룹으로 정리했습니다.
- 녹음 중 새 녹음 시작을 비활성화합니다. 진행 중인 녹음으로 돌아가는 기능은 유지합니다.
- 여러 항목을 선택한 뒤 선택한 항목에서 우클릭하면 전부 이동하거나 휴지통으로 보냅니다. 메뉴에 선택 개수를 표시합니다.
- 녹음·스크립트의 저장 상태, 편집 가능한 이름, 경로·날짜·길이를 문서 도구 모음에 정리했습니다. 독립 메모의 불필요한 ‘문서’ 표시는 제거했습니다.
- 녹음·스크립트에 전체화면을 추가했습니다. 연결된 메모에서 전체화면을 눌러도 스크립트와 메모, 하단 제어를 함께 넓힙니다.
- 새 그리기의 페이지 패널에서 페이지를 추가하고, … 메뉴 또는 길게 누르기로 복제·삭제합니다. 필기를 포함해 복제하고 삭제는 실행 취소할 수 있습니다. 페이지 미리보기에 필기도 표시합니다.
- PDF·그리기 도구에 단축키 안내를 추가했습니다. Ctrl+Shift+E는 펜·지우개 전환, Ctrl+Shift+H는 형광펜, Ctrl+D 뒤 1·2·3·4는 직선·화살표·사각형·타원 선택입니다. 텍스트 입력 창은 기존 테마에 맞춰 정리했습니다.
- 변환이 끝난 기록에서 ‘녹음 지우기’로 원본 음성만 휴지통에 따로 보관할 수 있습니다. 스크립트와 메모는 유지하고 원본을 복원하면 기존 기록에 다시 연결합니다.
- 원본 분리·복원을 중간에 종료해도 재실행 시 이동 기록으로 마무리합니다. 그리기 페이지 수도 저장된 문서에서 복구합니다.

## 사용 시 참고

- 저장 공간은 휴지통에서 원본을 영구 삭제한 뒤 확보됩니다. 영구 삭제하면 해당 기록의 재생과 다시 변환하기를 사용할 수 없습니다. 스크립트 복사·내보내기와 메모는 계속 사용할 수 있습니다.
- 페이지 추가·복제·삭제는 새 그리기에서 제공합니다. 불러온 PDF의 페이지 편집은 포함하지 않습니다. 그리기는 최소 1쪽, 최대 500쪽입니다.
- 도형 숫자 선택은 Ctrl+D로 메뉴를 연 뒤 숫자를 누르는 방식입니다. Ctrl+1~9의 오른쪽 탭 이동은 유지합니다.
- 기존 Work·Live 보관함, 녹음·스크립트·메모·모델·설정은 보존합니다.
