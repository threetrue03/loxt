# LOXT v2.9.0

메모·그리기를 더 편하게 사용하고, 내 기기 연결 과정을 이해하기 쉽게 개선했습니다.

- 그리기 전체화면의 바깥 여백·테두리를 제거해 작업 영역을 넓혔습니다. 종이 비율과 필기 좌표는 유지합니다.
- Python 등 코드 블록에서 마지막 줄의 삼중 백틱 뒤 Enter를 누르면 일반 문단으로 돌아갑니다. 실행 취소·다시 실행을 지원합니다.
- ROS2 Python·C++·YAML·XML·CLI·msg·srv·action 분류와 언어 검색을 추가했습니다. 코드 블록 안에서 바로 복사할 수 있습니다.
- 목차를 전체화면 버튼 오른쪽에 배치하고 H1~H4 글자 크기를 구분했습니다. 메모의 … 메뉴를 제거하고 터치 화면에 실행 취소·다시 실행 버튼을 제공합니다.
- Work·Live 홈에서 내 기기 연결을 열 수 있습니다. 같은 Wi-Fi → 인증서 설치·신뢰 → QR·주소 → PC 승인 순서로 안내하며 승인 요청을 상단에 표시합니다.
- QR의 실제 남은 시간을 표시하고 만료 시 재생성을 안내합니다. 대표 네트워크 주소와 다른 주소를 나누어 표시합니다.
- 승인한 브라우저의 별명 수정, 승인 기한과 실제 접속 상태 표시, 승인 해제 확인을 추가했습니다.
- 유효한 같은 브라우저 승인은 재사용해 중복 항목 생성을 방지합니다. 만료·해제되거나 다른 브라우저인 경우에는 PC 승인이 필요합니다.
- 웹 연결 관리에서는 현재 연결 상태에 맞춰 재연결·재승인을 안내하고 열린 문서와 저장 대기 초안을 유지합니다.

`LOXT-Setup-2.9.0-x64.exe`로 업데이트하세요. 기존 녹음·스크립트·메모·필기·폴더·모델·설정을 유지합니다. 연결한 웹 화면은 새로고침해 업데이트한 PC 버전을 사용하세요.

현재 설치 파일은 Authenticode 서명되지 않았습니다. 공식 릴리스와 SHA256SUMS.txt를 확인하세요. 체크섬은 게시자 서명을 대신하지 않습니다.
