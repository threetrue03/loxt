# Work 메모

## 사용 방법

녹음 상세 화면에서 변환이 끝나면 `전체 복사 / 내보내기 / 메모`가 표시됩니다. 메모를 눌러 오른쪽 패널을 열고 내용을 입력하세요. 닫거나 다른 페이지로 이동해도 메모는 유지합니다. 다시 변환하면 스크립트만 갱신됩니다.

녹음 없는 문서는 Work의 홈 또는 보관함에서 `새로 추가하기 → 새 메모`로 만듭니다. 현재 폴더에 저장되며 홈에서 만들면 내 보관함에 저장됩니다. 상단 제목을 눌러 이름을 편집합니다. 녹음과 같은 카드·목록·폴더·이동·휴지통 기능을 사용합니다. 휴지통 문서는 읽기 전용입니다.

## 편집

- `/`를 입력한 뒤 블록 이름을 검색합니다. `# `, `## `, `### `, `- `, `1. ` 등 Markdown 입력 규칙을 사용합니다.
- 텍스트를 선택하면 서식 도구가 표시됩니다. 기본 키보드 단축키와 Ctrl+Z/Shift+Ctrl+Z로 편집합니다.
- 블록 왼쪽 핸들을 잡아 이동합니다. 핸들을 클릭하면 복제·유형 변경·색상·삭제 메뉴가 열립니다.
- 토글 안에 하위 블록을 들여써 접거나 펼칩니다. 표는 단순 문서 표이며 데이터베이스가 아닙니다.
- 코드 블록의 언어를 선택해 구문 강조를 사용합니다. 코드에 커서를 놓고 문서의 `편집 도구 → 코드 복사`로 복사합니다.
- 수식은 LaTeX 소스를 편집하고 KaTeX/MathML로 표시합니다.
- 이미지·파일 블록의 업로드에서 PC 파일을 첨부합니다. 이미지 크기를 조절할 수 있습니다. 한 파일은 32 MB 이하이며 미리보기는 PNG/JPEG/GIF/WebP/BMP를 사용하세요.
- 검색 버튼 또는 메모 내부의 Ctrl+F로 문서에서 찾고 위·아래 버튼으로 결과를 이동합니다.

## 저장과 내보내기

자동 저장 상태는 `저장 중… / 저장됨 / 저장 실패`로 표시합니다. 실패하면 현재 작성 내용을 메모리에 유지합니다. 메모에서 다시 시도하세요. 저장을 못 마친 문서는 삭제하지 못하며 종료 요청도 저장 완료를 기다립니다. 강제 프로세스 종료·정전 직전의 아직 저장되지 않은 입력은 보장할 수 없습니다.

내보내기에서 Markdown, HTML, PDF를 선택합니다.

- Markdown: 기본 글·표·코드·수식 등을 내보냅니다. 색상·밑줄·토글 계층은 일부 단순화됩니다. GFM/수식 지원 여부는 여는 프로그램에 따라 다릅니다.
- HTML: SUIT와 이미지가 문서에 포함됩니다. 다른 첨부파일은 문서 옆 `.assets` 폴더로 복사합니다. 링크·서식 일부는 안전한 정적 HTML로 제한됩니다.
- PDF: A4 인쇄 문서로 만들며 접힌 토글도 펼쳐 출력합니다. 이미지·표·수식을 표시하지만 원본 첨부파일을 PDF 내부에 포함하는 기능은 없습니다.

HTML/Markdown과 함께 생성된 `.assets` 폴더를 삭제하거나 분리하지 마세요. 앱의 원본 JSON이 가장 완전한 문서이며 내보낸 파일의 완전한 재가져오기는 이번 버전에 포함하지 않습니다.

## 저장 구조와 호환성

기존 Work 보관함의 `recordings/<UUID>/` 안에 저장합니다. 녹음에 붙은 메모와 독립 문서 모두 `memo.json`을 사용합니다. 본문에는 스키마 버전·저장 revision·블록 JSON이 있고, `memo.json.backup`은 이전 정상 본문입니다. 첨부파일은 `attachments/<UUID>.<확장자>`에 저장합니다.

독립 문서의 `note.json`에는 `kind: memo`가 있습니다. 전역 `library.json`에는 제한된 텍스트 미리보기만 넣어 긴 문서 전체가 보관함 이벤트마다 전달되지 않게 합니다. 본문 저장은 직렬 처리·revision 검증·임시 파일·fsync·rename을 사용합니다. 손상된 본문은 백업을 표시하며, 저장 시 손상된 원본을 별도로 보존합니다. 정상 백업이 없는 손상된 문서를 빈 문서로 덮어쓰지 않습니다.

음성 변환은 메모를 대상으로 실행할 수 없습니다. 이전 버전 앱은 새 메모 유형을 이해하지 못하므로 메모 작성 후에는 1.13.0 이상을 사용하세요. 사용자 데이터에는 자동 마이그레이션이나 대량 삭제를 하지 않습니다.
