# LOXT v2.8.0

웹 연결이 끊긴 뒤 복구하는 과정과 모바일 문서 사용성을 개선했습니다.

## 변경 사항

- PC 연결 끊김, 승인 만료·해제, 다른 PC 연결 상태를 구분합니다. 열린 문서를 유지한 채 새 연결 주소로 재승인을 요청할 수 있습니다.
- 연결 관리에서 저장 대기를 확인하고 다시 연결하며, 메모·필기 초안 사본과 녹음 원본을 내려받습니다. 같은 PC에서 사본을 가져오면 원본을 덮어쓰지 않는 복구 문서를 만듭니다.
- 한 번 연결한 브라우저에 공개 복구 화면을 보관해, PC가 꺼졌을 때도 재접속 안내와 초안 다운로드를 제공합니다. 전체 문서 오프라인 편집은 지원하지 않습니다.
- 연결 요청 거절과 주소 만료를 구분하고, 만료된 기기가 승인 한도를 차지하지 않도록 수정했습니다. PC에 기기 승인 유효 기간을 표시합니다.
- 작은 화면·회전·키보드에 맞춰 PDF 텍스트 편집창과 필기 옵션을 배치합니다. 터치 버튼과 좁은 재생바, 낮은 가로 화면의 문서 공간을 개선했습니다.
- 사이드바 폴더 이동·삭제와 `library` 이름의 사용자 폴더를 수정했습니다. 녹음 버리기는 원본·연결 메모를 확인한 뒤 휴지통으로 이동합니다.
- 제목의 저장 대기·실패 표시, 오른쪽 탭 키보드 이동과 포커스, 녹음 중 버튼·미설치 기본 모델 안내를 개선했습니다.
- 설치 프로그램의 모델 버전 고정·무결성 검증·교체 실패 복구·저장 공간 검사와 준비 단계·재시도·오류 상세·언어 안내를 보강했습니다.

## 설치와 연결

`LOXT-Setup-2.8.0-x64.exe`로 업데이트하세요. 기존 녹음·스크립트·메모·필기·폴더·모델·설정은 유지합니다.

웹은 새로고침하여 현재 PC 버전을 사용하세요. 승인이 풀렸다면 PC 설정 → 내 기기 연결에서 **처음 연결하기의 연결 주소**를 받아 연결 관리에 입력하고 PC에서 승인합니다. 새 주소를 열기 전 저장 대기 초안과 녹음 사본을 내려받으세요.

현재 설치 파일은 Authenticode 서명되지 않았습니다. 공식 저장소의 릴리스에서 받고 함께 제공하는 `SHA256SUMS.txt`의 값을 비교하세요. 체크섬은 정식 게시자 서명을 대신하지 않습니다.

초안 복구에는 원래 PC의 원본 PDF와 첨부파일이 필요합니다. 브라우저의 사이트 데이터를 삭제하면 그 브라우저의 초안과 복구 화면도 사라질 수 있습니다.

검증 범위와 기기별 추가 확인은 [구현 보고서](implementation-2.8.0.md)를 참고하세요.
