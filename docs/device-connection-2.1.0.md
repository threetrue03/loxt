# 개인 PC 웹 연결 · 2.1.0

## 첫 연결

1. PC에서 LOXT를 실행하고 **설정 → 내 기기 연결**을 켭니다.
2. PC와 모바일을 같은 Wi-Fi에 연결합니다.
3. **처음 연결하는 방법**을 펼치고 초기 설정 주소를 복사합니다. 모바일에서 공개 인증서를 받아 PC에 표시된 지문과 비교합니다.
4. 아이폰·아이패드에서 인증서를 설치하고 설정 → 일반 → 정보 → 인증서 신뢰 설정에서 LOXT 인증서를 신뢰합니다.
5. PC에서 **연결 주소 복사**를 눌러 모바일에서 열거나 QR을 스캔합니다. 같은 주소는 5분간 유효하며 기기 한 대의 연결 승인에 사용됩니다.
6. PC의 연결 요청에서 기기를 확인하고 승인합니다. 연결한 브라우저에서 보관함이 열립니다.

Windows 방화벽에서 LOXT의 개인 네트워크 연결 허용과 공유기의 기기 간 통신 허용이 필요할 수 있습니다. 초기 설정 주소는 인증서 안내용이며 보관함을 제공하지 않습니다.

## 소개 사이트에서 이동

소개 사이트 상단 **LOXT로 가기** 또는 다운로드 아래 설치 완료 안내를 누르고 PC에서 복사한 연결 주소를 붙여넣습니다. 해당 브라우저에 재접속 주소만 저장합니다. 5분짜리 승인 토큰과 비밀번호는 저장하지 않습니다.

다음에는 같은 브라우저에서 저장한 주소로 이동합니다. **연결 주소 변경**에서 주소를 수정하거나 지울 수 있습니다. 다른 브라우저·새 기기·승인 만료 시 새 연결 주소로 승인해야 합니다. 브라우저가 사이트 저장소를 차단하면 주소를 기억하지 못할 수 있습니다.

소개 사이트는 PC를 자동 탐색하거나 실행하지 않습니다. PC와 연결이 끊겼는지를 이동 전에 확인하지 않으므로 PC 앱과 서버가 실행 중인지 먼저 확인하세요. PC가 사용하는 주소·포트가 바뀌면 새 주소를 등록합니다.

## 모바일 탐색

900px 이하의 웹 화면은 홈·보관함·최근·설정 하단 탐색을 사용합니다. 보관함의 휴지통 버튼으로 삭제된 기록을 관리합니다. 메모·PDF·녹음·스크립트를 열면 탐색 바를 숨기고, 기존 돌아가기 버튼으로 보관함에 복귀합니다. 넓은 화면과 PC 앱은 기존 사이드바를 유지합니다.

모바일 신규 Live 녹음은 제공하지 않습니다. Work 마이크 녹음은 전경 사용 기준이고, 변환은 PC의 설치된 모델과 GPU 또는 CPU에서 처리합니다.

## 연결 해제

PC 설정에서 연결된 기기를 해제하면 해당 브라우저의 승인이 취소됩니다. 서버를 끄거나 PC 앱을 종료하면 연결이 종료됩니다. 더 사용하지 않는 모바일의 LOXT 인증서는 기기 설정에서 제거할 수 있습니다.
