# LOXT v2.2.0

PC와 외부 기기 사이의 문서 저장·갱신 구조를 개선하고 PDF 읽기·필기 화면을 정리했습니다.

## 원격 동기화·저장

- 열린 녹음·메모·PDF 제목이 다른 기기의 변경을 따라갑니다. 편집하지 않은 제목으로 최신 이름을 덮어쓰는 문제를 수정했습니다.
- 연속 PDF 필기에도 저장이 계속 미뤄지지 않도록 최대 대기 시간을 적용했습니다.
- 문서 본문 저장과 보관함 목록 처리를 분리하고, 전체 스크립트 대신 짧은 목록과 필요한 문서의 상세 내용만 읽도록 개선했습니다.
- 중복 조회·모델 환경 요청을 줄이고, 연결 재시도·응답 제한 시간·화면 복귀 시 재동기화를 적용했습니다.
- 모바일 녹음 초안을 조각별로 저장합니다. 기존 초안의 이전·복구와 중복 조각 방지를 유지했습니다.
- 앱 종료 시 저장 대기 중인 메모·PDF를 확인하고 저장을 마친 뒤 닫습니다.

## PDF 읽기·필기

- PDF 영역에서 두 손가락으로 문서를 확대·이동합니다. 손가락 이동과 펜 입력을 구분하고 손가락 필기를 선택할 수 있습니다.
- 화면 너비 맞춤이 창 크기·패널 폭 변경을 따라가며, 문서별 페이지·배율·보기 위치를 기억합니다.
- 모바일 도구 모음과 하단을 간결하게 정리했습니다. 페이지 미리보기는 작은 화면에서 펼쳐 보는 방식으로 바뀝니다.
- 점 필기, 드래그 지우개, 손 도구와 Space 이동을 지원합니다.
- 도구별 색상·굵기, 텍스트 크기와 선택한 필기의 속성을 조절합니다. 텍스트 편집에서 Esc는 취소, Ctrl+Enter는 완료입니다.
- 검색 결과의 위치를 강조하고 PDF의 안전한 링크·목차를 탐색합니다.
- 페이지 로딩·저장·오류·재시도 상태와 키보드 조작 안내를 개선했습니다.
- 원본을 변경하지 않는 화면용 용지 톤을 선택할 수 있습니다.

## 안내

- 기존 녹음·스크립트·폴더·메모·PDF 원본·모델을 유지합니다.
- Windows x64 설치 파일: `LOXT-Setup-2.2.0-x64.exe`.
- 이번 검증은 별도 예시 보관함, Windows 앱, Edge 터치 자동화와 WebKit 엔진에서 진행했습니다. 실제 iPad/iPhone의 Safari·Apple Pencil 필압과 GPU 추론 성능은 이번 릴리스에서 새로 실측하지 않았습니다.
- 소개 화면의 예시 스크립트와 Live 상태는 UI 설명용이며 변환 정확도·속도 측정 자료가 아닙니다.

자세한 항목별 적용 내용과 측정 조건은 [통합 구현 기록](implementation-2.2.0.md)과 [검증 기록](verification-2.2.0.md)을 확인하세요.
