# LOXT v2.3.0

PDF 없이 시작하는 그리기 문서를 추가하고, 문서 전체화면과 모바일 PDF 확대 흐름을 개선했습니다.

- Work·Live의 ‘새로 추가하기 → 그리기’에서 빈 A4 한 페이지를 만들어 펜·형광펜·텍스트·도형으로 기록합니다. 기존 보관함 저장·이름 변경·이동·휴지통·PDF 내보내기를 이용합니다.
- PDF·그리기 상단에 돌아가기, 페이지 목록, 편집 가능한 제목, 경로와 페이지 번호를 모았습니다. 오른쪽에 저장 상태·내보내기·전체화면을 배치했습니다.
- 메모의 문서·저장 상태·제목·경로·날짜를 같은 도구 모음으로 정리하고, 내보내기 옆에 전체화면을 추가했습니다. 불편했던 옆쪽 블록 관리 메뉴를 제거했습니다. Markdown 입력과 슬래시 메뉴는 유지합니다.
- PDF 핀치 중 반복 렌더링을 줄이고, 모바일 캔버스 크기와 텍스트·이미지 캐시를 제한했습니다. 현재 페이지를 먼저 보여주고 검색 색인은 필요할 때 PC에서 생성합니다.
- 외부 기기의 32MiB 이상 PDF는 PC가 표시용 페이지를 만들어 전달합니다. 원본과 필기를 보존하며, 높은 확대율에서 표시 선명도는 제한될 수 있습니다.
- 모바일 탐색을 홈·보관함·설정으로 줄였습니다. 웹앱과 소개 사이트의 화면 확대 제스처를 제한하며, PDF·그리기 내부 확대는 유지합니다. 홈 화면용 LOXT 아이콘도 추가했습니다.

Windows x64 설치 파일: `LOXT-Setup-2.3.0-x64.exe`.

별도 예시 프로필에서 서비스 회귀 검사 91개, 패키징 앱과 승인된 웹 브라우저의 PDF·메모·동기화 검사를 진행했습니다. 약 91MB의 합성 PDF를 사용했으며 실제 사용자의 90MB 문서나 iPad Safari·Apple Pencil 성능을 실측한 결과는 아닙니다. GPU 추론·실제 마이크 성능도 이번 작업에서 새로 측정하지 않았습니다. 소개 화면의 예시 스크립트와 Live 상태는 UI 설명용입니다.
