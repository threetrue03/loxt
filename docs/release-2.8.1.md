# LOXT v2.8.1

메모의 중첩 목록을 더 깔끔하게 표시합니다.

- 중첩 목록과 펼친 접기 블록의 세로 안내선을 제거했습니다.
- 같은 단계에 선이 두 개씩 나타나던 표시 문제를 해결했습니다.
- 들여쓰기 간격, 목록 기호, 접기·펼치기, 글자 색상과 저장된 문서 구조는 유지합니다.

`LOXT-Setup-2.8.1-x64.exe`로 업데이트하세요. 기존 녹음·스크립트·메모·필기·폴더·모델·설정은 유지합니다. 웹 화면은 새로고침해 업데이트한 PC 버전을 사용하세요.

현재 설치 파일은 Authenticode 서명되지 않았습니다. 공식 릴리스와 함께 제공하는 SHA-256을 확인하세요. 체크섬은 게시자 서명을 대신하지 않습니다.
