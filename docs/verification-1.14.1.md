# LOXT 1.14.1 사이드바 긴급 수정 검증

## 원인과 수정

`src/styles.css`의 예전 접힘 스타일이 `.brand`에 `visibility:hidden`을 적용해 현재 그 안에 있는 펼치기 버튼을 숨겼습니다. 동시에 `.sidebar-toggle`을 절대 위치로 옮기는 규칙이 남아 버튼을 사이드바 밖 상단 중앙에 배치했습니다.

숨김 선언을 제거하고 접힌 버튼을 정상 레이아웃 안의 `position:static`으로 돌렸습니다. 기존 아이콘·테마·접힘 애니메이션·Work/Live 상태 로직은 유지합니다.

## 재현 및 회귀 검증

`node scripts/sidebar-ui-smoke.mjs`는 별도 임시 프로필을 사용합니다. 기존 사용자 보관함·로그인 프로필·모델을 사용하지 않습니다.

- 수정 전: Work에서 접으면 ‘사이드바 펼치기’ 버튼이 보이지 않아 실제 앱 테스트가 실패했습니다.
- 숨김 선언만 제거한 중간 단계: 버튼이 상단 중앙에 나타나 클릭 좌표 검사에 실패했습니다. 위치 규칙도 함께 수정했습니다.
- 수정 후: Work/Live × 다크/라이트 × 1440/860px 창, 총 8개 조건에서 마우스와 Enter로 반복 접기·펼치기를 통과했습니다.
- 버튼의 크기·사이드바 내부 배치·중앙 좌표 클릭 가능 여부·`aria-expanded` 상태를 검사했습니다.
- 렌더러 오류가 없었고 캡처에서 접힌 사이드바 상단의 버튼을 직접 확인했습니다.

패키징된 앱도 `node scripts/sidebar-ui-smoke.mjs release/stage5/win-unpacked/LOXT.exe`로 동일한 8개 조건을 모두 통과했습니다. 최종 실행 결과는 `test-results/sidebar-1.14.1/results.json`에 기록합니다.

이 변경은 CSS 수정입니다. 음성 녹음·GPU 변환·로그인 흐름을 변경하거나 해당 기능의 성공을 새로 주장하지 않습니다. 사이트 화면은 별도 예시 자료로 촬영합니다.
