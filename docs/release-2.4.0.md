# LOXT v2.4.0

기기 간 편집 반영을 개선했습니다.

- 변경된 메모 블록과 PDF·그리기 필기만 주고받도록 개선했습니다.
- 펜을 움직이는 중 다른 화면에도 임시 필기 미리보기를 표시합니다.
- 여러 브라우저 탭의 실시간 연결과 재연결 처리를 개선했습니다.
- 저장 중 놓친 갱신을 다시 확인하고 편집 충돌 시 초안을 보존합니다.
- 저장 기록 복구와 폴더 내보내기의 최신 필기 반영을 강화했습니다.
- PC·웹에 연결 상태와 동기화 진단을 추가했습니다.

Windows 설치 파일: **LOXT-Setup-2.4.0-x64.exe**

PC 앱 업데이트 후 외부 기기의 LOXT 웹 화면을 새로고침해 주세요. 실제 반영 속도는 Wi-Fi와 PC 상태에 따라 달라집니다.
