# LOXT v2.1.1

웹 연결 화면에서 주소를 다시 입력할 수 있도록 개선했습니다.

- **내 PC에 연결** 화면에 **연결 주소 다시 입력**과 **이 주소로 연결** 버튼을 추가했습니다.
- 잘못된 주소와 처음 연결에 사용할 수 없는 재접속 전용 주소를 입력칸에서 안내합니다.
- 만료된 연결 주소를 새 주소로 교체해 다시 승인 요청을 보낼 수 있습니다.
- 같은 페이지에서 `#pair` 토큰만 바뀌어도 연결 요청을 다시 시작합니다. 이전 대기 요청과 타이머는 정리합니다.
- QR·주소의 5분 유효 기간과 PC 승인 절차, 기존 기록·모델·설정은 유지합니다.

PC 앱의 **설정 → 내 기기 연결 → 처음 연결하기 → 연결 주소 복사**로 받은 주소를 웹 화면에 입력하세요. 주소 끝에 `#pair=…`가 필요하고 PC에서 승인해야 합니다.

이 웹 화면은 PC 앱이 제공하므로 **PC 앱을 2.1.1로 업데이트**해야 새 입력칸이 나타납니다. 소개 사이트 배포 파일만 교체해서는 PC의 웹 화면이 바뀌지 않습니다.

설치 파일: `LOXT-Setup-2.1.1-x64.exe`

다운로드 예정 주소: https://github.com/threetrue03/loxt/releases/download/v2.1.1/LOXT-Setup-2.1.1-x64.exe
