# 외부 라이선스 원문

이 폴더에는 모델과 주요 실행 구성요소의 라이선스 원문 사본을 보관합니다. 외부 저작권 고지를 변경하지 않았으며 LOXT의 MIT 라이선스로 대체하지 않습니다.

확인일, 다운로드 출처와 원문 사본 SHA-256은 [sources.json](./sources.json)에 기록되어 있습니다. 버전 태그가 없는 upstream 주소의 사본은 확인일의 내용입니다.

SUIT 등 글꼴의 원문은 [public/font-licenses](../../public/font-licenses/)에 있습니다. Python과 Electron에 포함된 추가 고지 및 설치한 Python 패키지의 라이선스는 각 배포본에도 보관됩니다.

이 목록은 모든 전이 의존성을 열거한 SBOM이나 설치 파일의 재배포 준수 감사를 의미하지 않습니다. GPL/LGPL 바이너리 등을 다시 배포할 때는 해당 바이너리에 정확히 대응하는 소스와 고지를 제공하는 조건을 별도로 이행해야 합니다. upstream 링크만 기록했다고 모든 재배포 의무가 완료되는 것은 아닙니다.
