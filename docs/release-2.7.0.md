# LOXT v2.7.0

긴 문서를 탐색하는 메모 목차와 파일 관리 개선을 추가하고, 보관함·문서 저장·원격 PDF 처리를 정비했습니다.

- **메모 목차**: `#`부터 `####`까지 네 단계 제목을 트리로 표시합니다. 제목을 누르면 해당 위치로 이동하며, 좁은 화면에서는 메모 안에 겹쳐 열립니다. Work·Live의 독립 메모와 녹음 옆 메모에 공통으로 제공합니다.
- **검색 개선**: 굵게·링크처럼 서식이 바뀌는 지점의 문구도 찾습니다. 첫 검색 결과 이동을 정리하고 터치 화면의 메모 도구 조작 영역을 확대했습니다.
- **메모 편집 개선**: 중간 블록만 삭제해도 하위 내용은 보존하고, 여러 블록을 선택해 Tab·Shift+Tab으로 함께 들여쓰기를 바꿉니다. `>`는 접기·펼치기 블록으로, 삼중 백틱은 코드 블록으로 변환합니다. 코드 언어 검색과 Docker 등 추가 언어를 지원하며, 토글의 들여쓰기 선과 색상 표시를 수정했습니다.
- **파일 종류 표시**: 녹음·스크립트·메모·PDF·그리기·폴더를 구분합니다. 여러 종류를 함께 드래그하면 녹음 수 대신 항목 수와 구성을 표시합니다.
- **카드 미리보기 수정**: 긴 스크립트의 전체 줄 수를 보존하고, Live 오른쪽 패널의 더 보기가 올바른 보관함을 조회하도록 수정했습니다. 드래그를 Esc로 취소한 뒤 첫 클릭이 무시되던 문제도 해결했습니다.
- **폴더 관리·복구**: 단일 폴더 이동을 지원하며, 폴더를 휴지통에서 복구할 때 빈 하위 폴더와 원래 구조를 함께 복구합니다. 동명 폴더가 있으면 기존 폴더를 보존하고 복구 경로를 분리합니다.
- **보관함 최적화**: 탐색 목록과 현재 폴더의 카드 미리보기를 분리하고, 120개 단위 조회와 목록 증분 갱신을 적용했습니다. 초기 파일 읽기·영역 선택·큰 메모 저장을 개선했습니다.
- **원격 PDF·캐시 개선**: 취소된 PDF 대기 작업을 제거하고 기기별 요청을 구분합니다. 문서·모델 검색 캐시에 용량 제한을 적용하고 웹 정적 자산의 캐시 재검증·압축을 정비했습니다.
- **UI 일관성**: 사이드바 새 녹음의 상시 테두리를 제거했습니다. YouTube 모델 선택도 Work 역할·별명을 표시하며, 빈 공간 메뉴에서 키보드로 이동할 수 있습니다.

기존 녹음·스크립트·메모·PDF·폴더·모델·설정을 유지합니다. 음성 인식 모델과 Live 변환 방식은 변경하지 않았습니다. 실제 속도는 문서 크기·PC·네트워크에 따라 달라집니다.

설치 파일: **LOXT-Setup-2.7.0-x64.exe** · Windows x64

소개 사이트·README·예시 화면·다운로드 URL을 2.7.0에 맞춰 준비했습니다. 공개 다운로드는 GitHub 릴리스에 설치 파일을 업로드한 뒤 제공됩니다.
