## 확인한 동작

- Work·Live 사이드바의 하위 폴더 기본 접기, 홈·최근 기록·휴지통 아이콘, Ctrl+Shift+S 토글.
- 새로 추가하기의 7개 항목·2개 구분선, 드래그 영역 선택, 선택한 3개 항목의 우클릭 이동·휴지통 이동.
- 연결 메모의 전체화면 버튼으로 스크립트·메모·하단 제어가 함께 확대되는 동작.
- 원본 분리 후 스크립트·메모 유지, 음성만 별도 휴지통 표시, 원래 기록에 복원. 영구 삭제·부모 기록 삭제·분리 중단 복구는 별도 저장 테스트로 확인.
- 그리기 페이지 추가·복제·삭제·실행 취소, 문서 버전 충돌 거부, 재실행 및 PDF 내보내기 페이지 수와 필기 보존. 목록 저장 중단 후 문서 스냅샷에서 페이지 수 복구.
- 펜·지우개 전환, 형광펜, 도형 메뉴 숫자 선택, 테마에 맞춘 텍스트 입력과 완료. 미리보기 SVG와 캔버스 크기가 일치하는지 확인.
- 연결한 웹에서 페이지 추가 시 PC 페이지 수 갱신. PointerEvent로 터치 길게 누르기 메뉴를 검증.
- 320·390·768px의 다크·라이트 PDF 화면에서 페이지 가로 넘침 없음.
- 가상 마이크 녹음 중 홈·사이드바 새 녹음 비활성화, 진행 중 녹음 복귀, 중단·버리기.
- 기존 PDF 펜·지우개·텍스트·검색·핀치, 메모 갱신, 모바일 녹음 조각 순서와 재실행, 정상 종료 시 PDF 저장 완료를 확인.

## 화면과 사이트

현재 패키징된 2.5.0 앱을 비공개 예시 프로필로 촬영했습니다. 47개 화면의 manifest 버전과 이미지 로딩을 확인했습니다. 새 촬영은 그리기 페이지 메뉴, 스크립트·메모 전체화면, 원본을 분리한 기록을 포함합니다. 사이트는 320·390·768·1440px에서 가로 넘침, 다크·라이트 미리보기, FAQ와 다운로드 주소를 확인했습니다. README의 홈 이미지도 갱신했습니다.

예시 음성은 무음 WAV, 스크립트와 Live 화자 데이터는 소개용으로 생성했습니다. 변환 정확도나 속도의 증거가 아닙니다.

## 검증의 한계

실제 iPad/iPhone Safari·Apple Pencil·물리 마이크·컴퓨터 소리·GPU 추론을 이번에 새로 검증하지 않았습니다. WebKit 및 합성 터치 이벤트는 실기기 검증과 구분합니다. 설치 파일 생성과 그 안의 실행본은 확인했으며 실제 사용자 설치를 덮어쓰는 설치·업데이트 실행은 하지 않았습니다. 기존 큰 PDF의 실기기 성능 검증 결과를 이번 변경의 성능 측정으로 사용하지 않습니다.

기기 승인 요청이 PC에 도착하기 전에 승인하던 테스트 하네스의 경쟁 상태는 요청 도착 대기를 추가해 수정했습니다. 앱의 승인 흐름 변경은 필요하지 않았습니다. 첫 촬영에서 발견한 필기 미리보기의 20px 아이콘 크기 상속은 페이지 크기를 명시해 수정하고 최종 설치본으로 다시 검증했습니다.
