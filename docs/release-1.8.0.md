# LOXT 1.8.0

홈을 녹음과 파일 변환을 바로 시작하고, 열어본 기록으로 돌아오는 화면으로 변경했습니다.

- Work 홈에서 새 녹음 시작·파일 불러오기를, Live 홈에서 Live 시작·파일 불러오기를 제공합니다.
- 최근 열어본 기록을 최대 4개 표시하고 앱을 다시 열어도 순서를 유지합니다. Work·Live 기록과 열람 이력은 분리합니다.
- 진행 중인 변환과 녹음이 있을 때 홈에서 작업을 확인하고 해당 기록으로 돌아갈 수 있습니다. 변환 진행률은 기존 대기열의 실제 수치를 사용합니다.
- 상위 폴더를 별도 영역에 표시하고 하위 보관함으로 이동할 수 있습니다.
- 처음 사용하는 보관함에는 첫 녹음 안내를 표시합니다. 열람 이력이 없으면 보관함으로 이동할 수 있습니다.
- 모두 보기에서 전체 기록 관리 화면으로 이동합니다. 기존 보기 방식·정렬·이름 변경·드래그·휴지통 기능을 유지합니다.
- 기존 차콜 색상과 SUIT 글꼴, 녹음·변환·화자·출력 장치 기능을 유지합니다.

기존 녹음·모델·스크립트·설정을 보존합니다. 열람 이력은 로컬에 저장하고 삭제된 기록은 홈에서 제외합니다.
