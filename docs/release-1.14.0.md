# LOXT v1.14.0

기록 옆에서 웹페이지와 다른 폴더를 함께 열고, Live에서도 메모를 작성할 수 있습니다.

## 새 기능
- Work·Live 공통 오른쪽 패널: 브라우저·LOXT 폴더, 여러 탭, 탭 복원과 패널 너비 조절.
- ChatGPT 로그인·메시지 응답·앱 재시작 후 로그인 유지 확인(1.14.0 일반 실행, Google 이메일 계정으로 직접 검증).
- 폴더마다 제목·내용·제목+내용 검색. Ctrl+F 검색, Ctrl+A 선택, Delete 삭제 확인, 이동·휴지통 이동 Ctrl+Z 실행 취소 / Ctrl+Shift+Z 다시 실행, Ctrl+1~9 탭 이동.
- Live 녹음 중 메모와 독립 메모. 스크립트·메모 사이의 폭 조절.
- 설정에서 Work·Live 보관함 위치 변경. 복사·검증 후 전환하고 기존 파일과 모델을 보존.

## UI·UX 개선
- 홈은 녹음·파일·YouTube 바로 시작과 내 보관함 중심으로 정리. 홈 생성 드롭다운과 최근 열람 영역 제거.
- 사이드바에서 루트 폴더 바로 만들기, 폴더 빈 공간 우클릭 생성 메뉴.
- 선택된 드롭다운은 체크만 표시. 사이드바 토글을 사이드바로 이동.
- 화자 1·2·3 배지를 시간 왼쪽에 표시하고 Live 듣는 중 커서 추가.
- 현재 녹음 장치 표시, 제목과 뒤로 가기를 같은 행에 배치.
- 메모·스크립트 내보내기 드롭다운, 완료·메모 카드 배지 제거, 다크·라이트 녹음 버튼 색상 정리.
- 토스트 페이드인·아웃 각각 1.5초, 전체 3초.

## 데이터와 사용 안내
기존 녹음·스크립트·메모·폴더·모델·설정을 보존합니다. 기본 기록 경로는 LOXT/work-library와 LOXT/live-library로 이전하고, 기존 설정·모델 경로는 호환성을 위해 유지합니다. 실행 취소 이력은 앱 실행 중에만 유지되며 영구 삭제를 복구하지 않습니다.

내장 브라우저는 기존 Chrome 계정과 자동 동기화하지 않습니다. 로그인 유지는 사이트 정책에 따릅니다. 1.14.0 일반 실행 환경에서 사용자가 Google 이메일 계정으로 ChatGPT에 로그인하고 메시지 응답을 확인했습니다. 앱을 정상 종료·재실행한 뒤 재로그인 없이 다시 메시지 응답을 받는 것까지 확인했습니다. 다른 계정 방식과 환경을 모두 검증한 것은 아닙니다.
