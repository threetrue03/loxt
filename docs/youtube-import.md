# YouTube 음성 가져오기 — LOXT 1.9.0

Work의 파일 불러오기 아래에서 작은 선택 창을 열고 링크 확인 → 영상 제목·채널·길이 확인 → 최상위 저장 폴더·모델 선택 → 음성 가져오기 → 기존 로컬 변환 순서로 처리한다. Live에는 이 진입점을 추가하지 않는다. 기존 차콜 UI, SUIT, Modal·Select·폴더 선택·TaskPanel·스크립트 프레임을 재사용한다.

## 구현과 범위

- `electron/youtube.cjs`: 일반 watch/youtu.be 링크를 단일 영상 주소로 정규화한다. 임의 사이트·파일 URL·Shorts·재생목록·라이브 방송·로그인 필요 영상을 거부한다. 서버에서 조회한 메타데이터는 30분짜리 1회 토큰으로 제출하며 렌더러가 제목·원본 경로·다운로드 옵션을 조작하지 못하게 한다.
- 공식 Windows yt-dlp 2026.08.19를 SHA-256 확인 후 설치 파일에 포함한다. EJS는 이미 포함된 Electron Node 런타임으로 실행한다. 별도 시스템 프로그램·FFmpeg·Python 설치를 요구하지 않는다. 가져오기에는 인터넷 연결이 필요하다.
- 영상 전체 대신 독립 음성 트랙 m4a/webm을 가져온다. 별도의 GPU 작업을 시작하지 않으며, 가져오기 완료 후 선택 모델을 보존해 `ConversionQueue`로 제출한다. 기존 Live 우선 처리와 Work GPU 직렬 실행을 유지한다.
- 실제 수신 바이트·파일 크기 또는 조각 수로 진행률을 표시한다. 측정 전에는 불확정 상태로 표시한다. 다운로드와 대기 취소는 사용자 라이브러리에 녹음을 만들지 않으며 임시 파일을 정리한다. 저장 중에는 취소 버튼을 비활성화하고 저장 뒤 변환 취소를 허용한다.
- 저장 후 변환 제출 실패 시 원본을 유지한다. 상세 화면에서 다시 변환할 수 있다. 일반 성공 기록은 영상 제목·원본 링크·채널·길이를 유지하며 제목·폴더 변경, 재생, 스크립트 복사·내보내기, 휴지통 처리도 기존 방식으로 동작한다.
- 확인 창을 닫거나 워크스페이스를 바꾸면 진행 중인 메타데이터 조회를 취소한다. 이미 제출한 다운로드와 변환은 페이지 이동 중 계속 실행된다. 진행 중인 다운로드를 마치거나 취소한 뒤 정상 종료할 수 있다. 강제 종료 후에는 해당 기능의 임시 다운로드만 정리하며 완료된 기록을 삭제하지 않는다.
- YouTube의 접근 제한·로그인 확인·삭제·네트워크 오류·음성 형식 오류를 안내한다. YouTube 변경에 따른 호환성 수정은 앱 업데이트를 통해 배포한다. 인증 쿠키·로그인 우회는 제공하지 않는다.

## 확인

`npm run test:release`는 기존 보관함·모델·변환·Live 테스트와 URL 검증, 메타데이터 유지, 다운로드 취소, 실패 후 원본 유지, 선택 모델 전달, 임시 파일 정리 테스트를 포함한다.

`npm run test:youtube`는 분리된 앱 테스트 프로필에서 실제 공개 영상 정보를 조회하고 음성을 가져온 뒤 CUDA로 변환한다. 최상위 폴더·모델 드롭다운, 작업 패널, 배경 워크스페이스 이동, Live와 기록 분리, 재생 메타데이터, 출처 열기, 이름 변경, TXT 내보내기, 재시작 후 기록 유지도 확인하고 화면을 저장한다. 테스트 기록과 사진은 배포 프로그램에 포함하지 않는다.
