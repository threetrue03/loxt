# LOXT 1.7.0

- Live 시작을 한 번 누르면 입력 권한 확인 → 모델 준비 → 자동 녹음으로 이어집니다.
- Live에도 Work와 같은 카드·작은 카드·목록 보기와 정렬, 중첩 폴더, 파일 불러오기 및 다시 변환하기를 제공합니다. 보관함은 각각 유지합니다.
- 카드 전체를 눌러 기록을 열 수 있습니다. 스크립트 미리보기에서는 텍스트 선택과 스크롤을 사용할 수 있습니다.
- 지나치게 넓던 모델 드롭다운을 수정하고, 기본 모델과 외부 모델을 각각 한 그룹으로 정리했습니다.
- Live의 기본 추천·성능 균형 안내 문구를 제거했습니다.
- 다시 변환하기를 텍스트 버튼으로 표시하고, 전체 복사는 버튼의 완료 애니메이션으로 알려줍니다.
- 컴퓨터 소리 녹음에 Windows WASAPI 루프백을 연결했습니다. 기본 출력 장치가 바뀌면 같은 세션에서 재연결합니다.
- Work·Live에 화자 A·B·C 표시를 추가했습니다. Live의 임시 표시를 종료 후 전체 녹음 분석으로 보정하고 복사·내보내기에도 화자 표시를 유지합니다.
- 설치 프로그램의 환경 준비에 화자 분석·출력 장치 엔진을 포함하고 준비 상태·다운로드 진행 및 모델 실행 검사를 안내합니다.
- 화자 분석 오류가 발생해도 Live 원본과 현재 스크립트를 저장하고 Work 대기열을 재개합니다.

기존 녹음·스크립트·모델·설정을 유지합니다. 기존 설치에서는 새 구성요소가 첫 사용 시 준비되므로 추가 다운로드가 필요할 수 있습니다.
