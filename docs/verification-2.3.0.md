서비스 전체 검사 최초 실행에서는 메모 복구·구형 보관함 이전 테스트가 아직 살아 있는 목록 쓰기 타이머와 겹쳐 실패했다. 재시작을 가정하는 테스트에서 `flushIndex()`를 먼저 기다리도록 수정하고 직렬 실행한 최종 91개가 통과했다. 이를 실제 사용자 데이터 손실 재현이나 제품 버그 수정으로 취급하지 않는다.

Playwright의 Electron 전체화면 스크린샷은 시간 초과가 발생했다. 기존 캡처 도구와 동일한 Electron `webContents.capturePage()`로 바꾼 뒤 검사와 캡처를 완료했다. 그리기 저장과 메뉴 동작 자체는 해당 시간 초과 전에 통과했다.

## 큰 PDF 측정

실제 최종 패키지 + 승인된 Edge 웹, Windows, 820×1180 CSS px, DPR 2, 터치 자동화. 고정 난수 이미지와 텍스트로 생성한 **95,727,064바이트(약 91.29MiB), 48쪽** 합성 PDF. 실제 사용자의 90MB 문서나 iPad 하드웨어와 동일한 조건이 아니다.

페이지 이미지 전송량은 페이지를 연 뒤 해당 확대까지 관측한 PNG/JPEG 응답의 합이다. 모든 JSON·글꼴·네트워크 트래픽을 포함하지 않는다. 위 수치는 단일 실행 관측치이며 반복 중앙값·메모리 피크·보편적 처리 시간이나 Wi-Fi 성능을 의미하지 않는다.

2.2.0 조사에서는 별도 305KB·8쪽 예시의 20회 핀치 이동에 캔버스 재설정 20회가 측정됐다. 문서와 실행 조건이 다르므로 이번 91MB의 시간과 직접 속도 배수로 비교하지 않는다. 개선의 확인 지표는 이동 중 재렌더 제거, 원본 전송 회피, 픽셀/캐시 상한 적용이다.

## 한계와 후속 확인

- 실제 사용자의 동일 PDF, iPad Safari에서 최초 열기/재열기/200–400% 확대/페이지 이동/필기 저장을 다시 확인해야 한다. 실기기 메모리 피크·Safari 종료·Apple Pencil 필압은 미측정이다.
- PC 페이지 이미지 생성은 CPU·임시 캐시 비용을 추가한다. 5MP 전체 페이지 예산은 높은 배율의 선명도를 제한할 수 있다. 고해상도 타일 렌더는 이번 범위에 포함하지 않았다.
- 검색 색인은 2백만 자를 제한하며 OCR을 제공하지 않는다. PC가 연결을 제공하는 동안만 원격 보관함·문서 처리가 가능하다.
- 실제 새 마이크/시스템 소리 녹음과 GPU 음성 추론을 이번 작업에서 새로 검증하지 않았다. 소개 사이트의 Live 스크립트와 화자 데이터는 화면 예시다.
