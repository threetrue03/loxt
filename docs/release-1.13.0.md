# LOXT v1.13.0

Work에 녹음과 함께 쓰는 메모와 독립 메모를 추가했습니다.

- 스크립트의 **내보내기 오른쪽 → 메모**를 누르면 오른쪽 패널이 열립니다. 스크립트와 메모는 각각 스크롤하며, 하단 재생바는 그대로 사용할 수 있습니다. 작은 창에서는 메모가 스크립트 위에 겹쳐 열립니다.
- Work 홈·보관함의 **새로 추가하기 → 새 메모**로 녹음 없이 문서를 작성합니다. 제목 수정, 폴더 이동, 카드·목록 보기, 최근 기록, 우클릭, 여러 기록 선택·이동, 휴지통 복구·영구 삭제와 연결됩니다.
- Markdown 입력과 `/` 검색 메뉴로 제목 1–3, 본문, 글머리·번호·체크 목록, 인용, 구분선, 토글, 표, 코드, 이미지·파일, 블록·인라인 수식을 추가합니다.
- 텍스트 선택 시 굵게·기울임·밑줄·취소선·링크·색상·인라인 코드 도구를 사용합니다. 블록 핸들로 이동·복제·삭제·유형 변경, 목록 들여쓰기, 실행 취소·다시 실행을 지원합니다.
- 문서 검색, 자동 저장, 저장 실패 후 재시도, Markdown·HTML·PDF 내보내기를 추가했습니다. 이미지·파일은 PC에 보관하며 첨부파일 하나당 최대 32 MB입니다.
- 메모 본문은 녹음·스크립트와 별도 JSON으로 저장합니다. 재변환 시 메모를 유지하며 저장 실패 시 작성 내용을 메모리에 보존하고 앱 종료·삭제를 막습니다. 이전 정상 본문 백업도 유지합니다.
- SUIT 글꼴과 기존 다크·라이트 테마를 유지합니다. 편집기는 메모를 열 때 로드합니다. Live의 녹음·변환 방식은 그대로입니다.

Markdown은 색상·밑줄·토글 등 일부 서식을 완전히 보존하지 못합니다. 원본은 앱의 구조화된 문서이며 HTML/PDF 내보내기도 첨부파일 자체를 PDF 내부에 넣는 기능은 제공하지 않습니다. HTML/Markdown과 함께 생성된 `.assets` 폴더는 파일과 함께 이동하세요.

Windows 설치 파일: **LOXT-Setup-1.13.0-x64.exe**. 기존 녹음·스크립트·폴더·모델·설정은 유지합니다. 보관함에 추가된 메모는 1.13.0 이상에서 사용하세요.

데이터베이스·협업·자동화·AI·다단 레이아웃·문서 버전 관리 기능은 이번 범위에 포함하지 않습니다.
