# LOXT 2.3.0 구현 기록

2026-10-09. 기존 사용자 보관함·모델·설정 대신 프로젝트 아래 별도 예시 프로필을 사용했다. 공개 GitHub·Cloudflare에 게시하는 작업은 수행하지 않았다.

## 문서와 화면

- 독립 그리기는 기존 PDF 보관함 형식을 재사용하며 `documentType: drawing`으로 구분한다. 빈 A4 한 페이지로 시작하고 기존 필기·텍스트·도형·저장 충돌 검사·내보내기·폴더·휴지통을 유지한다. 다중 페이지 추가 기능이나 OCR을 새로 제공하는 것은 아니다.
- PDF·그리기는 돌아가기 → 페이지 여닫기 → 편집 가능한 제목 → 경로·페이지 순으로 정리했다. 저장 상태·내보내기·전체화면은 오른쪽에 둔다.
- 독립 메모는 돌아가기·문서·저장 상태·제목·경로·날짜·메모를 표시한다. 독립/녹음에 붙은 메모 모두 내보내기 옆 전체화면을 제공한다. SideMenuExtension을 제거했으며 Markdown/슬래시/텍스트 서식 기능은 유지했다.
- 전체화면은 앱 내부 집중 보기다. 지원 브라우저는 popover의 최상위 레이어를 사용하고 이전 Safari에는 고정 배치 대체 경로를 제공한다. 메뉴도 문서 레이어에 표시한다. 종료·돌아가기·페이지 이동 시 상태를 정리한다.
- 모바일 하단은 홈·보관함·설정 세 버튼이다. 웹앱과 소개 사이트의 두 손가락 페이지 확대·Ctrl 휠/배율 단축키를 제한하고 PDF 내부 확대는 보존한다. iOS 입력 글꼴은 자동 확대를 피하도록 16px 이상을 사용한다.
- 기존 LOXT SVG에서 홈 화면 아이콘 180/192/512px를 생성했다. 설치된 이전 바로가기의 OS 아이콘 캐시 갱신 여부까지 보장하는 것은 아니다.

## 대용량 PDF 조사 L01–L08 적용

| 항목 | 적용 |
| --- | --- |
| L01 연속 배율 렌더 | CSS와 requestAnimationFrame으로 화면만 변환. 종료 후 160ms 안정화한 마지막 배율로 렌더. 화면 너비 맞춤도 180ms 대기 후 확정 |
| L02 캔버스 예산 | 터치/원격 페이지 약 5MP, 데스크톱 12MP로 출력 비율 조정. 별도 고해상도 타일 렌더는 추가하지 않음 |
| L03 전체 문서 선행 색인 | 오픈 시 기존 색인만 조회. 검색 요청 시 PC 별도 worker에서 제한된 색인 생성·재사용 |
| L04 텍스트/링크 비용 | 현재 페이지 내용 캐시, 제스처 중 함께 변환. 페이지 이미지와 텍스트 준비를 분리 |
| L05 캐시 수명 | 클라이언트 텍스트 6페이지, 원격 페이지 6개/이미지 4개, worker 텍스트 4개/래스터 3개. 문서 종료 시 정리 |
| L06 페이지 목록 | 보이는 범위와 여유 행만 마운트. 터치 환경은 기본 접힌 상태 |
| L07 이전 화면 지우기 | 별도 버퍼에서 렌더한 뒤 완료된 화면으로 교환 |
| L08 렌더 중 입력 | 같은 페이지의 확대·이동을 허용. 다른 페이지가 준비 중일 때 필기는 보호 |

외부 기기의 32MiB 이상 문서는 원본을 클라이언트 PDF.js로 해석하는 대신 PC worker에서 화면용 이미지·텍스트·링크를 생성한다. 이미지 페이지는 JPEG, 나머지는 PNG로 전달한다. 원본과 PDF 내보내기는 기존 방식으로 보존한다. 별도 검색 worker와 페이지 worker는 작업 큐·제한 시간·종료 정리를 갖는다. 페이지 worker는 30초 유휴 후 종료한다.

서버 미리보기는 별도 임시 폴더에서 최대 8개·2분 수명을 적용하며 재시작 후 이전 생성 파일도 정리한다. 사용자 원본이나 다른 내보내기 파일을 삭제하지 않는다. PC에 이미지 생성 비용이 추가되므로 이를 GPU 추론 속도 개선으로 설명하지 않는다. 전체 페이지 약 5MP 제한은 고배율 선명도와 메모리 사용 사이의 절충이다.

관련 구현: `src/PdfPage.jsx`, `src/pdfRemote.js`, `src/pdfViewport.js`, `src/PdfPageRail.jsx`, `src/documentView.js`, `src/MemoEditor.jsx`, `src/MemoPage.jsx`, `electron/pdfs.cjs`, `electron/pdf-worker.cjs`, `electron/pdf-jobs.cjs`, `electron/web-services.cjs`, `shared/web-gestures.js`.

## 릴리스 준비

앱·설치 파일·README·소개 사이트·다운로드 URL을 2.3.0으로 맞췄다. 현재 패키징 앱을 별도 예시 프로필로 촬영하며, 녹음/Live 예시는 실제 음성 인식 검증 자료가 아니다. 게시용 설치 파일·사이트 ZIP·릴리스 문서는 로컬 산출물이다. 실제 Release 업로드와 Production 배포는 사용자가 진행해야 한다.
