# LOXT — original concept 03

선택한 3번 시안의 심볼과 워드마크 도형을 그대로 사용합니다. 도형 간 비율, 선 두께와 글자 간격을 변경하지 않았습니다. 배경 및 단색 버전은 색상만 다릅니다.

- symbol: 파형 O 심볼 단독
- wordmark: LOXT 워드마크
- lockup: O 심볼과 LOXT 워드마크 가로 조합
- dark: 어두운 배경에 사용할 #D9D1BD 투명 로고
- light: 밝은 배경에 사용할 #5C5547 투명 로고
- mono-black / mono-white: 단색 투명 로고
- app-icon / LOXT.ico: 기존 시안과 같은 #D9D1BD 배경, #5C5547 심볼
- on-dark / on-light: 배경이 포함된 미리보기

SVG는 실제 벡터 도형과 패스이며 래스터 이미지를 포함하지 않습니다. Figma로 드래그하여 도형별 편집할 수 있습니다. SVG 파일을 텍스트 편집기로 열면 소스 코드를 확인할 수 있습니다.

LOXT 글자는 글꼴을 사용하지 않고 직접 만든 벡터입니다. 편집용 SVG 자체가 배포 가능한 패스·도형 버전입니다. PNG는 투명 RGBA이며 명시적으로 배경을 포함한 파일만 불투명 배경입니다. ICO는 16/24/32/48/64/128/256 px을 포함합니다.

Colors: #1E1E1E / #D9D1BD / #5C5547 / #FDFDFC. Monochrome: #000000 / #FFFFFF.
