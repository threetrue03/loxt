# LOXT 1.10.0

Windows용 로컬 녹음·음성 변환 앱입니다. 기존 소리노트의 기록과 모델을 이어 쓰며, 화면과 설치 프로그램의 이름은 LOXT입니다. 제공된 Craft 다크 화면을 기준으로 한 차콜 UI와 제공된 LOXT 로고를 사용합니다. 앱 글꼴은 오프라인 SUIT로 고정합니다.

## 1.10.0 — 다크·라이트 테마

**설정 → 일반 → 테마**에서 **다크 테마 / 라이트 테마**를 선택합니다. 기본값은 기존 다크 테마입니다. SUIT 글꼴과 배치를 유지하며 배경·글자·테두리·상태 색·드롭다운·팝업·스크립트·로고·시작 창·기본 Windows 창 테마를 함께 전환합니다. 라이트 테마는 옅은 회색 배경과 흰 패널, 차콜 글자를 사용합니다. Work와 Live는 하나의 테마 선택을 공유하고 즉시 반영하며, 다음 실행에도 유지합니다. 녹음이나 변환을 중단할 필요가 없습니다.

테마는 기존 모델·녹음 설정과 분리된 `%APPDATA%/sorinote-desktop/appearance.json`에 저장합니다. 저장 실패 시 이전 테마를 유지하고 일반 설정에 재시도 안내를 표시합니다. 시스템 테마 자동 전환은 제공하지 않습니다.

검증: `npm run test:theme`, `node scripts/library-interactions-smoke.mjs --theme`, `node scripts/live-smoke.mjs --theme`, `node scripts/splash-smoke.mjs --light`. 별도 테스트 보관함에서 기존 다크 화면 색상·배치, 라이트 화면과 메뉴, Work/Live 공유, 작은 창, 재실행 복원, 실제 Work 녹음 및 Live CUDA 동작 중 테마 전환을 확인합니다. 기존 다크 비교 기준은 테마 변경 전에 캡처한 `scripts/fixtures/dark-theme-baseline.json`입니다. 화면 캡처는 `test-results/theme-baseline.json`이 가리키는 별도 테스트 프로필에 저장합니다.

## 1.9.0 — YouTube 불러오기

Work 사이드바에서 **파일 불러오기** 바로 아래 **YouTube 불러오기**를 선택합니다. 공개된 일반 YouTube 영상 링크를 확인한 뒤 최상위 저장 폴더와 변환 모델을 선택하면 음성 파일만 가져와 기존 로컬 변환 대기열로 넘깁니다. 페이지·워크스페이스를 이동해도 작업이 계속되며 설정 위 진행률에서 가져오기와 변환을 개별 취소할 수 있습니다. 가져온 기록은 영상 제목으로 저장하고 상세 화면의 **YouTube 원본 열기**로 출처를 확인합니다. 이름·폴더·스크립트·재생·내보내기는 기존 기록과 같습니다.

Shorts·재생목록·방송·비공개·로그인이 필요한 영상은 지원하지 않습니다. YouTube가 추가 확인이나 지역 제한을 요구하면 원인을 표시합니다. 가져오기에 실패하면 불완전한 녹음을 보관함에 추가하지 않으며, 음성 저장 후 변환 제출만 실패한 경우에는 저장된 원본을 유지합니다. 공식 yt-dlp 2026.08.19를 SHA-256 확인 후 설치 파일에 포함하고 기존 Electron Node 런타임으로 실행합니다. YouTube 변경으로 가져오기가 막히면 향후 앱 업데이트에서 도구 버전을 올릴 수 있습니다.

검증: `npm run test:release`, `npm run test:youtube`. YouTube 화면 검증은 별도 테스트 프로필을 사용하며 설치된 모델·환경을 재사용합니다. 실제 공개 영상 조회·음성 가져오기·CUDA 변환·Work/Live 분리·원본 링크 보존·이름 변경·내보내기·재시작 복원을 확인합니다.

## 워크스페이스

상단 **LOXT 로고와 꺾쇠** 드롭다운에서 작업 공간을 전환합니다. Work는 기존 `library` 보관함을 그대로 사용하며 Live는 별도 `live-library` 경로에 폴더와 기록을 저장합니다. 모드를 바꿔도 Work 녹음과 변환은 계속됩니다. Live는 녹음 중 실시간으로 스크립트를 누적하고, 종료 후 원본 WAV와 확정된 스크립트를 별도로 보관합니다. 페이지와 워크스페이스를 이동해도 Live 입력은 계속됩니다. 모델 캐시는 기존 공용 경로를 유지합니다. 로고를 누르면 Work / Live 선택 메뉴가 열립니다. 홈은 사이드바에서 선택합니다.

## 사용 흐름

1. **새 녹음**을 열고 테두리가 있는 상단 제목에서 이름을 바로 수정합니다. 하단 **녹음 시작** 오른쪽 화살표에서 위로 열리는 메뉴로 마이크를 선택합니다. 불러온 파일에는 마이크 선택을 표시하지 않습니다.
2. 하단의 **녹음 시작**을 누릅니다. 녹음 시간·입력 파형·일시정지·중단이 같은 하단 영역에 표시됩니다.
3. **녹음 중단**을 누르면 원본을 먼저 저장하고 작은 선택 창을 엽니다. 폴더와 모델을 고른 뒤 **변환하기**를 누르면 필요한 준비와 음성 변환이 자동으로 진행됩니다. 별도 자동 변환 체크박스는 없습니다.
4. 가운데 **스크립트** 프레임에서 결과를 스크롤합니다. 완료되면 하단은 재생·구간 이동·속도 조절이 가능한 재생바로 바뀝니다. 스크립트 줄 전체를 누르면 해당 시점으로 이동합니다. 완료된 스크립트 프레임 우측 상단의 **내보내기**로 TXT를 저장합니다.

선택 창을 닫아도 저장된 원본은 보관함에 남습니다. 불러온 파일이나 미변환 원본은 하단의 **변환하기**로 같은 선택 창을 열 수 있습니다. 완료된 기록은 재생바의 다시 변환 아이콘을 사용합니다.

페이지를 이동해도 녹음과 변환은 계속됩니다. 녹음 중에는 사이드바의 **녹음으로 돌아가기**로 같은 녹음에 복귀합니다. 변환은 파일별로 선택한 모델을 유지하고 한 파일씩 처리합니다. 설정 위의 진행률·파일 이름·추가 대기 수를 누르면 작업별 진행률과 개별 중단 버튼을 확인할 수 있습니다. 대기 중인 파일을 취소해도 다른 파일의 변환과 원본은 유지합니다. 앱을 강제 종료한 작업은 재실행 시 중단 오류로 표시하고 재시도할 수 있습니다.

보관함은 어두운 카드와 목록 보기를 제공하며 카드 안에서 전체 스크립트를 스크롤할 수 있습니다. **새로 추가하기 → 폴더 / 새 녹음 / 불러오기**를 사용합니다. 폴더 안에서 새 폴더를 만들면 하위 폴더가 되고, 기존 녹음은 관리 창에서 하위 폴더로 이동할 수 있습니다. 설정은 **일반**부터 열립니다. 사이드바는 224px이며 접고 펼칠 때 아이콘 높이를 유지하면서 슬라이드합니다. 시작 시 제공된 LOXT 로고를 담은 작은 창이 0.6초 페이드 인·0.3초 유지·0.6초 페이드 아웃 후 닫힙니다.

폴더 제목은 **내 보관함 › 상위 폴더 › 현재 폴더** 경로로 표시합니다. 상위 경로를 누르면 해당 폴더로 이동합니다. 긴 경로는 창 너비에 맞춰 **…**으로 접고, 생략 메뉴에서 상위 폴더를 선택할 수 있습니다.

녹음의 **점 3개 버튼 / 우클릭 → 이름 바꾸기·폴더 이동하기·휴지통으로 이동** 메뉴를 사용합니다. 이름은 카드나 목록에서 바로 편집하며 Enter 또는 다른 곳 클릭으로 저장하고 Esc로 취소합니다. 폴더 이동 메뉴 안에서 하위 폴더를 펼쳐 목적지를 선택합니다. 휴지통에서는 복원을 제공합니다. 폴더를 우클릭해 이름 바꾸기를 선택하면 메인 페이지에서 편집할 수 있고, 현재 폴더 제목은 두 번 클릭하거나 F2로 편집합니다. 폴더 이름 변경은 하위 경로와 모든 녹음의 소속을 함께 갱신하며 원본 파일 위치는 유지합니다. 저장 중 중단된 폴더 변경은 재실행 시 복구합니다. 접힌 사이드바의 토글 버튼은 로고 아래에 표시합니다.

## 모델과 하드웨어

| 표시 이름 | 모델 | 다운로드 용량 | 용도 |
| --- | --- | --- | --- |
| 저성능 | small | 약 486 MB | 자원 부담이 작고 빠른 변환 |
| 표준 | large-v3-turbo | 약 1.62 GB | 속도와 정확도 균형 |
| 고성능 | large-v3 | 약 3.09 GB | 정확도 우선 |

실행 장치는 앱에서 자동으로 선택합니다. NVIDIA GPU가 감지되면 CUDA를 사용하고, NVIDIA GPU가 없는 PC에서는 CPU를 사용합니다. AMD GPU 추론은 지원하지 않습니다. 메모리 부족 등 실행 오류는 안내하며 더 작은 모델로 다시 시도할 수 있습니다.

설치 프로그램에서 모델을 여러 개 선택하거나 앱의 **설정 → 모델 보관함**에서 설치할 수 있습니다. 설치·실행 검사를 연결하고, 앱에서는 같은 모델 행에 진행률·취소·재시도를 표시합니다. 모델 보관함의 선택 버튼과 녹음 종료 선택 창에서 사용할 모델을 고릅니다.

**외부 모델 불러오기**는 faster-whisper/CTranslate2용 로컬 폴더를 받아 관리 폴더로 복사합니다. `model.bin`, `config.json`, `tokenizer.json`이 필요합니다. 기본 모델 아래의 외부 모델 구역과 변환 모델 목록에 표시합니다. 최초 변환 시 실제 모델 실행을 검사합니다. 일반 Whisper `.pt`나 GGML 파일을 그대로 받는 기능은 아닙니다. 외부 모델을 삭제해도 불러온 원래 폴더와 기존 녹음·스크립트는 유지합니다.

## 설치·업데이트·삭제

- 배포 파일: `release/stage5/LOXT-Setup-1.10.0-x64.exe`
- 설치된 앱이 없으면 신규 설치, 구버전이면 **업데이트 / 앱 삭제**, 같은 버전이면 **앱 복구 / 앱 삭제**를 제공합니다. 더 최신 버전의 다운그레이드는 차단합니다.
- 소리노트와 LOXT 실행 파일·제거 프로그램을 모두 인식합니다. 앱 ID `local.sorinote.desktop`과 기존 사용자 데이터 경로를 유지합니다.
- 업데이트는 앱을 닫고 새 설치 파일을 실행합니다. 녹음·스크립트·설정·모델을 유지합니다. 자동 업데이트 서버는 운영하지 않습니다.
- **앱 삭제**는 앱·모델·전용 Python·변환 환경을 삭제하며 녹음·스크립트 보관함은 남깁니다. 업데이트 과정의 제거에서는 모델과 환경도 유지합니다.
- 마침 화면에서 앱 실행과 바탕화면 바로가기를 선택합니다. 모델·환경 준비 중 취소와 창 닫기는 해당 준비 프로세스와 하위 작업을 중단합니다. 받은 모델 조각은 이어받을 수 있습니다.
- Python 3.13.16을 포함하므로 별도 Python 설치가 필요하지 않습니다. 최초 모델·엔진 설치에는 인터넷과 저장 공간이 필요합니다. 시스템 Python 패키지는 변경하지 않습니다.

기본 보관함은 `%APPDATA%/sorinote-desktop/library`이며 모델·엔진은 같은 상위 폴더의 `transcription`에 있습니다. 모델 및 설치 로그는 `transcription/models/installer-preparation.log`에서 확인합니다. 앱 이름 변경에 따른 데이터 이동은 하지 않습니다.

무인 설치는 `/S /MODELS=small,large-v3-turbo`로 모델과 환경을 준비할 수 있습니다. `/MODELS=none`은 모델 설치를 생략합니다. `/ACTION=update`, `/ACTION=repair`, `/ACTION=delete`를 지원하며 실행할 수 없는 작업은 종료 코드 3, 준비 실패는 2를 반환합니다. `/PREPARE=0`은 모델 파일만 설치합니다. 설치 프로그램의 `/DEVICE=cpu` 또는 `/DEVICE=cuda`는 준비 장치를 지정하지만 앱 변환은 자동 실행 장치를 사용합니다.

## 개발과 화면 확인

Node.js 22.12 이상에서 `npm ci`로 의존성을 설치합니다.

- `npm run dev`: Electron 앱과 개발 서버 실행
- `npm start`: 화면 빌드 후 Electron 실행
- `npm run dev:web`: 웹 화면만 실행
- `npm run package`: 포함된 Python과 함께 `release/stage5/win-unpacked/LOXT.exe` 생성; 폴더 전체가 필요합니다.
- `npm run package:installer`: 단일 설치 파일·`SHA256SUMS.txt`·`release.json` 생성
- `npm run preview:design` 또는 **LOXT 디자인 테스트.cmd**: 별도 테스트 보관함으로 화면 확인

디자인 테스트 보관함은 `test-results/design-preview.json`에 지정합니다. 예제 기록과 테스트 음성은 테스트 폴더에만 두며 배포 앱과 실제 사용자 보관함에 추가하지 않습니다. 제공된 원본 로고는 `design/loxt-white`, 앱용 SVG는 `src/assets/brand`에 있습니다. `npm run assets`는 원본 심볼의 비율과 둥근 선을 유지한 Windows 아이콘을 생성합니다.

## 1.3.0 사용 흐름

- 변환과 재변환 중에는 스크립트 영역에 스켈레톤을 표시합니다. 기존 스크립트는 완료될 때까지 화면에서 숨기며, 실패·취소 시 기존 결과는 보존됩니다.
- 펼친/접힌 사이드바의 로고를 누르면 새 녹음으로 이동합니다. 진행 중인 녹음이 있으면 그 녹음으로 돌아갑니다.
- 폴더 이동은 별도 트리 메뉴에서 선택합니다. 모든 드롭다운은 차콜 메뉴로 통일했습니다.
- 내 보관함은 시스템 루트이며 실제 폴더나 모델/저장 폴더 선택 옵션으로 생성되지 않습니다. 폴더를 지정하지 않은 녹음은 루트에 저장됩니다. 녹음 종료 후 저장 화면에는 최상위 사용자 폴더만 표시합니다.
- 폴더 삭제 시 하위 폴더도 제거하고 녹음을 휴지통으로 이동합니다. 삭제한 폴더의 녹음을 복구하면 내 보관함에 저장됩니다. 진행 중인 녹음/변환이 있는 폴더는 삭제할 수 없습니다.
- 휴지통은 체크박스와 모두 선택, 복구, 삭제, 모두 비우기를 제공합니다. 영구 삭제는 확인 후 원본과 스크립트를 삭제하고, 복구할 수 없습니다. 삭제 기록을 먼저 저장하여 재실행 시 파일이 되살아나는 것을 방지합니다.
- 전체 복사는 시간 표시 없이 스크립트 본문을 클립보드에 복사합니다.
- 녹음 장치에서 컴퓨터 소리를 선택하면 Windows 출력 오디오를 녹음합니다. 화면 영상은 저장하지 않습니다. 마이크와 컴퓨터 소리는 각각 선택하며 동시에 혼합하지 않습니다. 컴퓨터 소리는 Windows 기본 출력 장치의 소리를 사용합니다.
- 검증: `node scripts/workspace-actions-smoke.mjs`, `node scripts/system-audio-smoke.mjs`, `node --test scripts/trash.test.cjs`. 컴퓨터 소리 검사는 짧은 테스트 음성을 출력해 실제 녹음 파형을 확인합니다.

## 1.6.0 — Live 실시간 변환

- LOXT 로고의 워크스페이스 메뉴에서 **Live → 새 Live 녹음**을 선택합니다. 제목, 변환 모델, 입력 장치를 고르고 **Live 시작**을 누릅니다. 기본 모델은 표준입니다. 필요한 모델·실행 환경은 자동으로 준비하며, 준비가 끝난 뒤 녹음을 시작합니다.
- 하단 시작 버튼의 화살표에서 마이크 또는 **컴퓨터 소리**를 고릅니다. 음성은 16 kHz 모노 PCM으로 저장하고 모델은 세션 동안 계속 로드합니다. 실행 장치는 NVIDIA GPU가 있으면 CUDA, 없으면 CPU로 자동 선택합니다.
- 2초마다 인식 중 미리보기를 갱신합니다. 0.5초 침묵 또는 연속 음성 6초에서 구간을 확정하며, 0.6초 문맥을 겹쳐 분석합니다. 6초 경계의 마지막 0.6초는 다음 구간에서 확정합니다. 입력 에너지로 분석 시점을 정하고 실제 인식에는 Silero VAD를 적용합니다. 최소 음성 길이는 0.3초입니다.
- 확정 스크립트와 인식 중 문장을 구분합니다. 위로 스크롤하면 자동 스크롤을 멈추고, 맨 아래로 돌아오면 이어서 따라갑니다. 하단에서 일시정지·계속·종료할 수 있습니다. 일시정지한 시간은 원본 길이에 포함하지 않습니다.
- 홈·설정·Work로 이동해도 녹음을 유지합니다. **Live 녹음으로 돌아가기**로 입력 화면에 복귀합니다. 기존 Work 변환은 현재 파일을 마친 후 Live를 시작하고, 나머지 Work 작업은 Live 종료 후 재개합니다.
- 종료하면 남은 구간을 처리하고 Live 보관함에 저장합니다. 원본 재생, 스크립트 구간 이동, 전체 복사·내보내기, 이름·폴더 관리·휴지통을 사용할 수 있습니다. Work 보관함과 기본 모델 선택은 유지합니다. Live의 저장 폴더는 시작한 보관함 위치를 사용합니다.
- 확정 문장과 원본을 주기적으로 체크포인트 저장합니다. 비정상 종료 후 저장된 원본과 확정 문장을 복구합니다. 엔진 오류 시 원본 녹음은 계속하며 종료로 저장할 수 있습니다. 저장 오류는 재시도 가능합니다. 아직 확정하지 않은 미리보기는 복구 대상에 포함하지 않습니다.
- GPU/CPU와 모델에 따라 실제 지연·정확도가 달라집니다. Live 지연이 길어지면 화면에 표시합니다. Work의 종료 후 파일 변환과 Live의 짧은 구간 변환은 문맥 길이가 달라 결과가 같지 않을 수 있습니다.

검증: `npm run test:release`에 Live WAV·복구·구간·AudioWorklet 리샘플링·취소·저장 재시도·Work 대기열 테스트를 포함합니다. `npm run test:live`는 별도 테스트 보관함과 가상 음성 입력으로 실제 CUDA 변환, 페이지 이동, 일시정지, WAV 길이, 스크립트 시간, 재생·복사·내보내기를 검사합니다. 이 로컬 GPU 검증 스크립트는 현재 PC의 모델 캐시와 지정된 테스트 음성을 사용합니다.


## 1.6.1 — 녹음 UI와 Live 모델 준비

- 로고 메뉴의 테두리와 선택 배경을 제거하고 현재 Work/Live 모드를 작게 표시합니다. 카드 보기의 폴더는 녹음 카드 위에 따로 배치합니다.
- Work/Live 새 녹음 제목은 입력 길이에 맞춰 늘어나고, 녹음 타이머는 `시:분:초`로 표시합니다. Work의 녹음 준비 문구를 제거하고 변환 창에는 왼쪽 버리기, 오른쪽 변환하기를 배치합니다.

- Live 모델 선택은 하단 시작 버튼 왼쪽으로 이동합니다. 첫 클릭은 모델 준비만 진행하며 실제 다운로드 진행률 또는 모델 로딩 상태를 같은 버튼에 표시합니다. 준비 완료 후 다시 **Live 시작**을 눌러야 오디오 녹음과 타이머가 시작됩니다.
- 모델을 변경하면 준비 상태를 다시 확인합니다. 녹음 전 다른 페이지로 이동하면 준비된 GPU 세션을 해제해 Work 대기열을 재개합니다. 실제 녹음 중에는 페이지를 이동해도 유지합니다.
- 출력 장치 자동 추적과 화자 분리는 후속 설계 문서에 기록하며 이번 버전에 포함하지 않습니다.

## 1.7.0 — Live 자동 시작과 화자 분리

- 카드 전체를 눌러 기록을 엽니다. 스크립트 미리보기는 텍스트 선택·스크롤 영역으로 유지합니다.

- Live 보관함에도 Work의 카드·작은 카드·목록 보기, 정렬, 하위 폴더와 드래그 이동을 제공합니다.
